# docs/

## このディレクトリは何か

- `additional_infos`: agent へ指示する際に必要となる追加情報のテキストを配置するものである．
- `lectures`: リポジトリの理論的説明（数式レベルから，アーキテクチャ単位の説明：論文的，学術的な説明を想定）を配置するものである．
- `plans`: agent への指示を配置するものである．
- `reports`: 実装レベルの報告を配置するものである．

## agent がすべきこと

- 触ってはならないもの: `additional_infos`, `plans`
  - これらは私が指示したり配置したりするもので，agent は触れてはならない
- 更新すべきもの: `lectures`, `reports`
  - `lectures` には，現状の実装の理論的解説を日本語で記載した md ファイル等を配置する
    - `current-architecture` には，現在のリポジトリ内の構造を示した dot ファイルおよびそこから生成した svg ファイルを配置し，構造が変更され次第ここも変更すること．
  - `reports` には，ひとつの実装群が終わった時（イメージとしては plans 内の指示ひとつごとに対応するが，口頭での指示も含まれるので，必ずしも対応している必要はない．しかし，規模感としてはひとつの plan ファイルくらいである），その内容を実装レベルで説明するものである．
    - 理論的内容は `lectures` に任せ，ここでは実装レベルの報告書となる．
