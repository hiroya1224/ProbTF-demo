## 重要な設計判断

- IMU frame config は、観測 message の frame とモデル計算用 frame を同一視しない。
- static TF は URDF に IMU frame が無い場合の補助機構とし、URDF 側で定義済みなら使わなくてよい optional なものにする。
- quasi-static mode の通常の平衡姿勢変化は、IMU の動的加速度ノイズとしては扱わない。
- `qs_noise_std_deg` / `qs_vib_amp_deg` が作る摂動だけを finite difference し、synthetic IMU の角速度・加速度へ反映する。
- `K` の推定分布は `log K` 空間の Gaussian として扱う。従って、初期標準偏差も `log_kp0_std` として設定する。
- `K` 空間で不確かさを表示する場合、`log K` の +/-2 sigma は上下非対称な `K * exp(+-2 sigma_log)` になる。
- debug viewer では `K_exec` に推定共分散帯を直接重ねない。`K_exec` は推定値ではなく、実行側に平滑化された制御用の値だからである。
