# 正方形底面と四側面の箱把持デモの精査

2026年10月14日に正方形底面100×100 mm、高さ180 mmの箱へ訂正した。姿勢分布は上向きz軸を保つ0・90・180・270度の四回転からなるC4混合であり、各x軸が四側面の外向き法線を一つずつ指す。四成分は一つの把持候補の内部に保持する。誤った以前の構成のコード・映像・記録・図と実測値は削除または置換し、今回の根拠として残していない。

log-sum-expの目的関数、最適化、再始動、位置・移動費用、関節制約、初期角、制御器と経路生成は前回の実装から維持した。IK本体を含む共有8ファイルはbaseline `687cf0b` とバイト単位で一致する。正方形の入力、共通上向きz、四側面のx法線をproducer、独立bag解析、図生成で検証する。旧非正方形や上下反転のモードを渡すと検査を通過しない。

表示上はxとyの軸端点が同じ場所へ重ならないよう、物体枠の軸長を赤x=180 mm、緑y=120 mm、青z=180 mmとした。この指定は表示だけに作用し、物理箱・目標分布・IKを変更しない。指定を省略すると従来どおり三軸を同じ長さで描く。native点群とモード枠の表示から、赤4方向・緑4方向・青上向き1地点と、処理後の分布不変を検証した。

既存のIK/Binghamを含む合同検証98件と、表示の独立検証5件、合計103件が通過した。ROS I/Oを除く有限混合samplingと点群生成は実コードを使う。Cryptodomeの既存の非推奨module警告は検査の成否に影響していない。

ROS masterをport11982へ分離して両条件を撮り直した。混合条件は665標本、単一条件は669標本で、両条件が位置・方位・開口の到達基準を満たした。全観測姿勢での最小箱隙間下限は2.954266061 mmと2.647277976 mm。混合条件は基準−90度のモードを選び、手首曲げ角28.101799801度、移動量費用1.530358949となった。単一条件は基準モードを選び、92.371814125度と3.509213032だった。この一例の差を一般性能へ拡張しない。

native物体と把持目標は混合条件で各226メッセージ、単一条件で各229メッセージだった。すべてで成分数、重み、κ=5000の行列、上向きzと側面法線を照合した。全1334行の観測の幾何と全5種類のIK費用を独立に再計算し、記録との差は0だった。最後の2秒は各60標本で、位置2 mm、最寄り方位2度、開口0.2 mmの基準を満たす。詳細は `actual-c4-review.json` と `box-scope-and-live-audit.json` に記録した。

斜めと真上は一つのX11フレームから分岐して記録し、混合条件の各視点453フレーム、単一条件456フレーム、全て20 fpsだった。生画面、動画、bag、観測CSVと設定を保存した。説明字幕は加えていない。物体や腕による一部の軸端点の遮蔽は画面のまま残る。
