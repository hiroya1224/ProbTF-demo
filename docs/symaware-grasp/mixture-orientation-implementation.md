# 混合Bingham方位費用の実装監査

基準はProbTF-demoのコミット `41920ae63062f24f3671aacb602fd2d22f5121d8` である。変更した本体は `ros/examples/symaware_grasp/src/symaware_grasp/symmetry_aware_ik.py` に限定した。各把持候補は、従来どおり一つの `TransformDistributionStamped` として全成分を保持する。

旧方位費用は各成分の二次形式を重み付きで加算していた。辺長がすべて異なる箱のD2対称性を四元数の基底4方向で表し、各方向の集中度を同じ値κにすると、重み付きパラメータ行列は `-3κ/4 I` となる。そのため旧費用では、4モードとその間の方位を区別できない。改訂後は、正規化済み重み `w_i` とBingham正規化定数 `C(A_i)` を使い、方位費用を `-logsumexp(log(w_i) + q.T @ A_i @ q - log(C(A_i)))` とした。

正規化定数は既存の `probtf.bingham.bingham_log_normalizer` で計算する。候補モデルを作る際に、最大固有値が0となる既存のパラメータ表現を取得し、`log(w_i)-log(C(A_i))` を保存する。正規化定数は行列の固有値だけで決まるので、正規化した固有値列と積分分割数をキーとして最大256件をキャッシュする。目的関数の反復評価では積分を実行しない。既存の重み正規化が重み0の成分を除外するため、`log(0)` は評価しない。目的関数では最大の対数密度を引いて指数を計算し、`math.fsum` で合計する。

位置費用は従来の成分ごとの共分散逆行列を用いる重み付き二次費用を保存した。移動量、関節制約、初期姿勢生成、再始動、候補の選定、最適化法も保存した。ソース構文木の比較では、`SymmetryAwareIKSolver` の8メソッド中、変更は `evaluate_cost` のみであり、残る7メソッドは一致した。差分に加えた処理は、成分モデルの事前計算と正規化定数のキャッシュである。`ik-scope-check.json` に構文木監査の結果とソースのハッシュを記録した。

単一成分では、新方位費用は旧費用に `log(C(A))` を加えたものとなる。したがって数学的な勾配と極小点は変わらない。ただし既存のL-BFGS-Bは、目的値の減少を `max(abs(f_old), abs(f_new), 1)` で割る相対停止条件も使う。定数の加算で分母が変わるため、すべての入力で停止時刻と返される数値解が同じになるとは保証できない。最適化設定は変更していない。今回の単一成分検算では、最大勾配差は `2.23e-12` 未満、最大関節角差は `2.91e-7 rad` 未満であり、旧・新ともに23反復、189回の目的関数評価で終了した。既存の代替勾配降下法では、厳密演算における勾配の停止条件と費用の大小関係は定数加算で変わらず、浮動小数点の丸め差が残る。

追加した回帰検算は8ケースであり、次の性質を調べた。

- D2の4モードで費用が一致し、その間の方位では費用が高くなる。
- 重みと集中度が異なる2成分について、球面上の独立な積分表示による正規化定数と照合する。
- 四元数の符号反転とパラメータへの定数行列の加算で費用が変わらない。
- 単一成分では位置・移動・関節費用が一致し、方位費用の差が定数となり、勾配と最適化解が一致する。
- 集中度5000でも4モード、中間方向、関節角方向の数値勾配が有限となる。
- 重み0の一様成分を追加しても有限Bingham検査と費用に影響しない。
- 同じスペクトルの正規化定数を再利用し、目的関数評価中には再計算しない。

集中度30では、モード費用は `-1.2788543681634545`、2モードの中間方向は `13.027998145374603` となった。集中度5000では、`log(C(A))=-10.365379949540769`、モード費用は `-8.979085588420878`、4座標が等しい方向は `3739.6346200504595` となった。球面密度は1を超えることがあるので、正規化負対数密度の費用は負となり得る。既存の候補選定、結果メッセージ、解析コードには方位費用が非負であるという条件はない。

追加8ケース、既存 `tests/symaware_grasp/` 全件、既存 `tests/probtf/test_bingham.py` を合わせて63件が通過した。既存テストの修正は不要であった。正規化定数の精度は既存の数値積分に従う。今回の積分分割数80では、軸対称分布の独立な積分との誤差が対数正規化定数で `3e-5` 以下になることを検算した。全パラメータに対する誤差上限を証明したものではない。

再現用の回帰テストは `tests/symaware_grasp/test_mixture_orientation_cost.py`、詳細な数値記録は `ik-check.json` に保存する。処理系にはcatkin環境の `/usr/bin/python3` を使用した。評価対象は目的関数と運動学であり、接触・摩擦・把持力は扱わない。既存のIKの `success` は有限費用の候補を得たことを示すので、箱の到達誤差と幾何的隙間はbag解析で別途確認する。
