# 混合Bingham方位費用と正方形断面の箱の検算

現行の方位費用は、各把持候補の正規化されたBingham混合密度の負の対数 `-logsumexp(log(w_i) + q.T @ A_i @ q - log(C(A_i)))` である。各把持候補は、一つの `TransformDistributionStamped` の内部で全成分を保持する。成分ごとの負の二次形式を重み付き平均する費用は用いない。IK本体は `ros/examples/symaware_grasp/src/symaware_grasp/symmetry_aware_ik.py` に実装する。

比較対象は寸法 `100 × 100 × 180 mm` の箱である。正方形断面を持つこの直方体の対称回転のうち、上向きのz軸を保つ四回転を採用する。基準方位をq0とし、モード四元数を `q_k = q0 ⊙ [cos(kπ/4), 0, 0, sin(kπ/4)]`、`k=0,1,2,3` とする。物理方位のヨーは90度ずつ異なる。全モードのz軸は上向きであり、x軸は箱の側面の外向き法線 `+X,+Y,-X,-Y` となる。この比較で用いる部分群はC4であり、箱を上下反転する対称回転は候補へ含めない。

成分重みは1/4、成分行列は `A_k = κ(q_k q_k.T - I4)` とする。実行条件の集中度はκ=5000である。四つのモード四元数は、上向きのz軸を保つヨー回転の二次元平面にあり、四次元の正規直交基底ではない。この平面の直交射影をPとすると、`sum_k q_k q_k.T / 4 = P/2`、`sum_k A_k / 4 = κ(P/2 - I4)` となる。今回のwxyz座標では `P=diag(1,0,0,1)` であり、平均行列は `diag(-κ/2,-κ,-κ,-κ/2)` である。上向きを保つ任意のヨー四元数はこの平面上にあるため、負の二次形式の重み付き平均はκ/2で一定となり、四方向のモードを選ぶ規準にならない。平面の外では一定ではない。

正規化された混合密度を用いると、四モードの費用は一致し、モードから45度離れた中間ヨーの費用は高くなる。大きな集中度での中間ヨーとモードの費用差は `κ sin²(π/8) - log(2)` に近づく。基準ヨー67.5度、κ=5000の検算では、モード費用は約 `-8.979085588421`、中間ヨー費用は約 `722.560814264651`、差は `731.5398998530713` となった。同じz軸を保つ33方位で二次形式平均を評価すると、値は `2499.9999999999986` から `2500.0000000000005` の範囲であった。集中度30でも費用差は `3.7002517128337242` であり、四モードを区別した。

正規化定数は既存の `probtf.bingham.bingham_log_normalizer` で計算する。候補モデルを作る際に、最大固有値が0となるパラメータ表現と `log(w_i)-log(C(A_i))` を保存する。固有値列と積分分割数をキーにして、最大256件の正規化定数をキャッシュする。目的関数の反復評価では積分を実行しない。重み0の成分は既存の重み正規化で除外する。目的関数では最大の対数密度を引いて指数を計算し、`math.fsum` で合計する。積分分割数80、集中度5000でも費用と関節角方向の数値勾配が有限であることを検算した。

位置費用は成分ごとの正則化した共分散逆行列を用いる重み付き二次費用、移動量は現在角との差の二乗和の半分である。関節制約、初期姿勢生成、再始動、候補選定、最適化法も維持する。正方形断面の箱への更新では、コミット `687cf0b` にあるIK本体から変更していない。ソースSHA256は `5e3349f0975392eb6e09d82fce1483b1612666c30d3a094c21be7993c8bd63d5` である。`ik-scope-check.json` に今回の一致を記録し、正規化密度を導入した際の構文木監査も保持する。

単一成分の正規化負対数密度は、固定行列の負の二次形式に `log(C(A))` を加えたものであり、数学的な勾配と極小点は変わらない。ただし既存L-BFGS-Bの相対目的値減少による停止条件は目的値の絶対値に依存するため、定数加算後の停止時刻や返される数値解まで一般に同一とは保証しない。単一成分検算では最大勾配差は `2.23e-12` 未満、最大関節角差は `2.91e-7 rad` 未満であり、双方とも23反復、189回の目的関数評価で終了した。

`tests/symaware_grasp/test_mixture_orientation_cost.py` の9ケースでは、基準ヨー0度と67.5度における四モードと45度の中間ヨー、二次形式平均の連続ヨーに対する一定性、異なる重みと正規化定数、四元数の符号とパラメータの定数加算、単一成分の勾配と解、集中度5000の有限性、重み0の除外、正規化定数の再利用を確認した。既存の球面積分との照合も保持する。今回の独立積分との比較で対数正規化定数の差が `3e-5` 以下となることを確認したが、全パラメータの誤差上限を証明したものではない。

箱の解析器は、manifestだけを信頼してモードを照合せず、正方形断面、長い鉛直寸法、上向きで共通のz軸、四つの異なる側面法線を独立に確認する。native ObjectBeliefのモードも確認する。`tests/symaware_grasp/test_box_trial_analysis.py` の15ケースと合わせて24件が通過した。箱の到達誤差と隙間は実bagから別途評価し、接触、摩擦、保持力や持上げは評価しない。球面密度が1を超える場合、方位費用は負となり得る。既存のIKの `success` は有限費用の候補を得たことを示すので、物理的な把持成功と同一視しない。

詳細な数値は `ik-check.json`、再現用のC4検算は `check_c4_cost.py` に保存する。処理系にはcatkin環境の `/usr/bin/python3` を使用した。実試行の結果は、この目的関数の回帰検算と分けて記録する。
