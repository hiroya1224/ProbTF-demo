# 正方形四側面への訂正後の全体精査

デモと新しい撮影結果は `1aa4ab9`、論文の訂正は `b85d5ae` としてmainへpushした。今回の対象は100×100×180 mmの正方形底面を持つ箱であり、同じ上向きz軸のまま、各x軸が四つの側面の外向き法線を一つずつ指すC4四成分である。

旧構成の動画・bag・図・再生成入力と旧数値は削除または新しいC4記録へ置換した。現行のデモには二方向だけの構成や上下を反転したモードを選ぶ設定はない。誤構成を渡した場合には、producer・bag解析・図生成の検査が受け付けない。旧構成を復元する選択肢をデモへ残していない。

103件の検証が通過し、IK・運動学・制御・経路生成を含む共有8ファイルは `687cf0b` と同一である。表示用の軸長だけは赤・緑の点群を区別するため180/120/180 mmへ指定した。指定なしの従来表示と、表示処理後の分布不変も検査した。

実記録の全1334標本、native物体・把持目標の全メッセージ、IKの全費用を独立に再計算した。混合条件は基準−90度の側面を選び、手首曲げ28.1018度・移動量1.5303589、単一条件は92.3718度・3.5092130だった。両条件が運動学的な到達基準を満たし、全観測の箱隙間下限は2.954266 mmと2.647278 mmだった。この差は今回の配置と初期角の一例である。

論文全体のビルドと `dvipdfmx -C 16 -V 7` が成功した。368ページすべてが縦向きで回転属性0であり、図6.5とcaptionは283ページ内で一緒に90度回転する。図・数式・表6.3（284ページ）を独立に目視した。861の本文ラベル、102の図表caption、22の既定見出しについて検査し、参照切れ・重複した参照先・ページ外文字・TeXの参照や引用の異常は0だった。

現在の図とSVG/PNG/PDF、入力チェックサムからの再生成が一致することも確認した。濃度、物理形状、初期角、費用の重み、制御器、カメラと切り出しは両条件で共通である。実際の遮蔽は残し、画面へ説明字幕を加えていない。接触・摩擦・保持力・持上げを確認した結果として扱っていない。

全体PDF検査と目視の記録は論文側の `docs/box-grasp/`、分布と費用・幾何の照合は `docs/symaware-grasp/actual-c4-review.json`、共有ソースの照合は `box-scope-and-live-audit.json` に保存した。この精査は修正の実装commitから分けて共有する。
