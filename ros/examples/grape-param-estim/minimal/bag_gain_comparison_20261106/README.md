# grape rosbagのXY・Zゲイン比較

2026-11-06。元のrosbagを直接開き、2026-06-12の9本と2026-06-13の3本、計12本の `/gimbalrotor/controller/{xy,z,roll_pitch,yaw}/parameter_updates` を全件読み取った。既存の機体推定・PIDマップは変更していない。

## 結果

数値の順序はすべて **(P, I, D)**。XYはX・Yに共通の設定群である。

| 実験日・bag番号 | XY | Z | 備考 |
|---|---|---|---|
| 二日目 6/13 #1・#2・#3 | (4, 0.1, 2) | (5, 1, 2.5) | 各bagの設定更新は各群1件、途中変更なし |
| 一日目 6/12 #1〜#7 | (3, 0.1, 1) | (5, 1, 2.5) | 各bagの設定更新は各群1件、途中変更なし |
| 一日目 6/12 #8 初期〜225.299秒 | (3, 0.1, 1) | (5, 1, 2.5) | 222.769秒に適用フラグを有効化、数値は同じ |
| 一日目 6/12 #8 225.299〜229.979秒 | (3, 0.1, 2) | (5, 1, 2.5) | XYのDを変更 |
| 一日目 6/12 #8 **229.979秒以降** | **(4, 0.1, 2)** | **(5, 1, 2.5)** | 二日目とXY・Zがともに一致。bag終端は357.816秒 |
| 一日目 6/12 #9 | **(4, 0.1, 2)** | **(5, 1, 2.5)** | 初期設定から二日目とXY・Zがともに一致、途中変更なし |

したがって、**Zは成功・失敗の既存代表ケースを含む全12本で共通**。**XYも一日目の#9、および#8の229.979秒以降に、二日目と同じ設定がある**。

ただし、既存資料で明示的に失敗として扱っている#4（failure1）と#6（failure2）では、Zは共通だがXYは異なる。#8・#9を日付だけで失敗と分類しない。#8前半の浮上・高度維持は、下記のmocap Z座標で確認した。#9には離陸後STOPの試行と、その後にHoverからLandへ移る試行が含まれており、比較する成否は区間単位で別に確認する必要がある。状態名だけで実際の安定飛行や墜落を判定していない。

二日目のRoll/Pitchは(13, 1, 20)、Yawは(6, 1, 2)。一日目#9ではこれらも一致する。一日目#8ではRoll/Pitchを複数回調整しており、XY・Zが一致し始める229.979秒時点ではRoll/Pitch=(13, 1, 12)。Roll/PitchのDが20になる322.701秒以降は、四群すべての記録ゲインが二日目と一致する。

## #8前半のmocap Z座標による確認

ユーザーの追加指定に従い、元bagの `/gimbalrotor/mocap/pose`、`geometry_msgs/PoseStamped`、frame=`world` の生Z座標を直接確認した。時刻はbag開始基準のrecord timeで、統計へ平滑化や欠測の仮値は入れていない。

| 区間 [s] | Z平均 [m] | 最小〜最大 [m] | XYゲイン |
|---|---:|---:|---|
| 初期 0〜8.5 | 0.24537 | 0.24520〜0.24579 | (3, 0.1, 1) |
| 40〜225.299 | 0.84771 | 0.76574〜0.91122 | (3, 0.1, 1) |

後者は22,235件の測定で、XYのDを変更する前の約185.3秒間にわたる。初期位置から平均で約0.602 m上がった状態が継続しており、#8では **XY=(3, 0.1, 1)、Z=(5, 1, 2.5)の間にも浮上・高度維持できている**。動画についてのユーザーの観察とも整合する。値はmocap追跡対象の世界Z座標であり、床からの高さやCoG位置へ読み替えない。Roll/Pitch等はこの間に調整されているため、全12ゲインが既存失敗例と同じとの意味ではない。

[証拠JSON](evidence.json)の `bag8_mocap_z_check` に、区間・件数・統計・原topicを保存した。この確認は飛行のZ方向についての観察であり、全状態の漸近安定性やXY追従誤差を評価したものではない。
