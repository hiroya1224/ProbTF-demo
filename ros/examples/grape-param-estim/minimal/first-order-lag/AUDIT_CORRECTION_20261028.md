# 一次遅れPIDマップの監査修正

2026年10月28日。入力はユーザー指定の `ProbTF_first_order_lag_audit_20261027.pdf`。監査対象コミットは `42a01528b915d1cc852c3b11e8396dc055d8934f`。

## 問題と修正

従来の実装は、成功ゲインで安定だった機体標本だけを分母に取り、他の9ゲインも成功記録の値へ固定していた。この条件では成功点の100%が定義で保証される。「失敗記録だけから、まだ知らない安定ゲインを予測する」という要件に適合しない。成功情報は範囲、anchor、初期trimとそのcacheにも使われていた。分母だけを直しても解決しない。

修正後は、失敗記録から得た元の全標本を順序も含めて固定する。全12ゲインを指定した制御器を `K`、第n標本の閉ループ行列を `F_n(K)` として、

\[
Q(K)=\frac{1}{N}\sum_{n=1}^{N}
\mathbf 1\{F_n(K)\text{ の評価が有効かつ }
\rho(F_n(K))\text{ が有限で }\rho(F_n(K))<1\}
\]

を計算する。今回の `N` は両ケースとも128。未評価・非有限の標本も分母から落とさず、安定数に加えない。その件数は別に保存する。安定標本が一つもない参照点でも、条件付き母集団が空という理由で計算を止めない。

単一群の3D図では他9ゲインを、その失敗記録の値に固定する。2D図ではさらに隠れた1ゲインも失敗値へ固定する。範囲・anchor・探索順・初期trim・warm-start cacheへ成功データを使わない。成功入力は任意とし、指定された場合だけ全マップ完成後に別計算で全12ゲインを評価する。断面へ成功ゲインの一部を投影した「Success点」は描かない。

これは有限のモデル標本に対する、ホバリング近傍の局所線形安定割合である。実飛行の成功確率や格子点間の保証ではない。異なる群の良い点を組み合わせた制御器も、全12ゲインを同時に評価する必要がある。

## 変更箇所

- `pid_gain_contour.py`：全N分母、失敗値固定、成功非依存の範囲・初期計算、終了後の独立参照比較、新schemaと別出力。
- `run_all_pid_gain_contours.py`：同じ失敗制御器・全標本による集計へ変更。成功を起点にした群別原因帰属の集計を撤回。
- 旧 `pid_gain_region.py`：成功値による範囲拡張と投影点を撤回し、surrogate構築不能標本も全Nの中に保持。局所surrogateと隠れ軸への最大化という従来の近似は明記し、exactな新3D結果と混同しない。全12参照比較はsurrogate成立集合から独立させた。
- `pid_gain_voxels.py`、`automation/pid_gain_voxels_interior.py`、`automation/pid_gain_voxels_fast.py`：通常・interior・fastの全経路を同じ原則へ変更。
- `automation/pid_voxel_survival.py`：全Nに対する安定数、有効数、未評価数を分離。主出力は `stability_fraction.npz/json`。
- domain、viewer、catalog、実行wrapper：成功依存の範囲と表示、成功100%の強制を撤回。catalogは既定ではローカルの準備だけを行う。
- `pid_gain_contour_affine_legacy.py`：旧成功条件付き入口を撤回。歴史コードは保存し、現在の解析には使用しない。
- `AGENTS.md`：同じ誤りを再導入しない条件を明記。

旧publicationのNPZ・図・計算snapshotは保存した。入口と文書に「撤回済みの歴史資料」と明記し、新結果とは別にした。旧stable bitsの分母だけを変更して、新しい失敗値固定図を作ったと説明することはしていない。

## 実際に再計算した結果

[修正後のビューアーとデータ](publication/pid_gain_voxels_failure_only_20261028/README.md) を別ディレクトリへ保存した。成功ファイルは指定していない。両失敗ケースについて、全128標本、seed 0、同じ `conservative_fusion` 共分散を使い、4群を再計算した。

粗格子3→5を実行した。失敗記録の値を正確なanchorとして挿入するため、最終の実配列は各軸6点、1群216点である。2ケース×4群で1728点。各ケースの計算時間は約82.7秒（各8 worker）。公開したのは最終5格子のデータと図で、中間checkpointは含めない。

| ケース・群 | 計算した範囲・格子内の最大安定数 | 128標本すべてが安定な点 |
|---|---:|---:|
| 失敗1 Roll/Pitch | 125/128 = 97.65625% | 0 |
| 失敗1 XY | 74/128 = 57.8125% | 0 |
| 失敗1 Z | 68/128 = 53.125% | 0 |
| 失敗1 Yaw | 66/128 = 51.5625% | 0 |
| 失敗2 Roll/Pitch | 127/128 = 99.21875% | 0 |
| 失敗2 XY | 17/128 = 13.28125% | 0 |
| 失敗2 Z | 16/128 = 12.5% | 0 |
| 失敗2 Yaw | 30/128 = 23.4375% | 0 |

全1728点で未評価標本数は0だった。この結果では、他群を失敗値に保持したままRoll/Pitchを変える場合と、他の群だけを変える場合の違いが大きい。これは旧成功値固定図とは別の問いに対する結果であり、他の群が重要でないことや、未探索領域に安定点がないことを意味しない。

33・65格子の失敗値固定マップは今回再生成していない。旧65格子の図を、新方式の高解像度結果としては使用できない。今回の粗格子が大域最適解や未知制御器の安定性を保証するとも主張しない。

## 原推定・標本を変更していない検証

[sample_identity.json](publication/pid_gain_voxels_failure_only_20261028/validation/sample_identity.json) に独立検証を保存した。

- 両ケースの全128×13座標は、従来保存標本とdtype・形状・順序・全バイトが一致。
- 原estimateとpublicationコピーの計4ファイルは、監査対象コミットの内容と全バイト一致。
- 全12失敗ゲインを再評価した安定数は失敗1が62/128、失敗2が15/128で、PDFの数値と一致。
- この参照点では、全128標本のスペクトル半径も旧保存値とbitwise一致し、最大差は0。
- 最終NPZの全標本の半径から `Q` を独立再集計し、保存された `stable_fraction` と全要素が一致。

従って今回変更したのは、成功情報に依存していたゲイン解析・統計量・表示である。機体の元推定を成功fitへ取り替えたり、都合の悪い標本を取り除いたりしていない。

## 回帰検証

成功時に不安定だった標本を保持すること、NaN/infでも分母が不変なこと、成功入力を変えても範囲・初期計算・fingerprintが変わらないこと、他9ゲインが失敗値であることをテストした。viewerは最終archiveだけから再描画でき、旧成功100%を前提としない。

実行したテストの件数と結果は、新publicationの `validation/tests.json` に記録する。既存の全12ゲイン探索 `pid_safe_margin_full.py` と、元の一次遅れ同定・物理モデルの実装は本修正で変更していない。
