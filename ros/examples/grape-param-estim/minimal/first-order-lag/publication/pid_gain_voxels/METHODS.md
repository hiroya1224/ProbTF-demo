# 判定と比較の範囲

主図は、failure 1・2からそれぞれ推定したモデル分布で、Roll/Pitchの成功・失敗ゲインを比較するものです。各ケースの格子は独立に計算したもので、両ケースの分布を混ぜていません。

生存率は従来の定義を使います。全成功ゲインで有限なスペクトル半径ρ<1だった固定サンプル集合S0を基準にし、候補ゲインでもρ<1を保つ割合を評価しています。

```text
Q(g) = 1 - count{s in S0 : rho_s(g) >= 1 or nonfinite} / |S0|
green = Q(g) >= 0.95
red   = Q(g) < 0.95
```

failure 1のS0は127サンプル、failure 2は128サンプルです。Success自身の生存率は定義上100%です。95%はこの固定集合での条件付き割合の閾値です。

Successは(P,I,D)=(13,1,20)。Failureはfailure 1で(20,1,8)、failure 2で(10,1,8)です。全点を通るI=1の断面に点を置き、断面外の点を投影していません。失敗点の生存率は71/127=55.91%、18/128=14.06%です。どちらも95%未満なので赤です。

Roll/Pitch以外の9ゲインは成功設定に固定して評価しています。Failureの点は記録された失敗飛行のRoll/Pitchゲインを代入した位置です。Yaw・XY・Zの単独置換では記録ゲインが緑に入るため、この結論の対象はRoll/Pitchです。

セルは計算ノードの値を隣接ノード間の中点で区切った区間に表示しています。黒い境界もセルの辺に沿います。面の回帰や補間は使っていません。3DではI<1を表示から取り除き、両点があるI=1面を露出させています。面上の色は主図の断面と同じ値から作っています。

再描画用のNPZは元の計算結果から書き出した配列です。保存した生存率とビット列を照合済みです。図を整理する際も数値配列は変更していません。`validation/bundle_validation.json`に、各点が厳密な計算ノードであることと、Successが緑・Failureが赤になることの検証結果を記録しています。
