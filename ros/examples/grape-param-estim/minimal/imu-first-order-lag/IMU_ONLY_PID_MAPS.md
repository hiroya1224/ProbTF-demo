# IMUだけを帰還に使うPID図の規準

2026-11-06。今回のユーザー指定は、mocapを帰還に使わず、姿勢だけでなく位置・速度もIMUから推定し、推力・gyro・accelの三つの一次遅れを含める構成である。旧mocap版・理想状態帰還版とは別出力にする。

入力は `publication/imu_native_20261031` のfailure1・failure2の同定結果である。身体パラメータ13座標と三つのlog時定数からなる16次元共同Gaussian、全共分散・交差項、入力のSHAを保持する。比較に使う有限個の座標・順序・重みも固定し、復号不能な点を捨てて分母を減らさない。成功記録の身体推定値は使わない。

## 旧図と同じ厳密な安定規準を使う場合

旧26状態モデルは理想的な状態帰還を仮定している。今回は、真の機体状態、アクチュエータ状態、gyro・accelのセンサ状態、推定器・制御器の内部状態を含む拡大状態を \(x\) とする。PIDを \(k\)、機体・三時定数を \(\theta\)、雑音を零にした一周期の写像を \(\Psi_{k,\theta}\) と書く。

hoverの固定点 \(x_*\) が存在するとき、従来の全状態の局所漸近安定規準は

\[
J_{k,\theta}=D\Psi_{k,\theta}(x_*),\qquad
\rho(J_{k,\theta})<1
\]

である。したがって図の対象は、単に姿勢が落ち着く割合ではなく、

\[
Q(k)=\Pr_{\theta}\!\left[
\text{安定なhover固定点が存在し、全拡大状態の }\rho(J_{k,\theta})<1
\right]
\]

となる。旧理想26状態モデルの数値を、このIMU-only拡大系の結果と表示してはならない。

この図生成では、特定の新しい位置・速度観測器を実装して数値シミュレーションしたわけではない。以下の証明は、IMUと過去の指令だけを使う任意の因果的な観測器について、この全状態規準を直接決める。三つの推定時定数も証明の対象に含めるが、その値によって他の極がどこへ動くかは今回数値評価していない。

## 真の位置には必ず単位固有値が残る

現在の自由飛行モデルは一様な重力を使い、絶対位置に依存する力・観測を持たない。速度依存の抗力があっても、以下の位置の議論は変わらない。gyro・accel、必要なら一様磁場の地磁気観測も、真の位置そのものには依存しない。

\(E_p a\) を、**真の機体位置だけ**に \(a\in\mathbb R^3\) を加え、推定位置、目標、速度、姿勢、センサ・制御器状態を変えない摂動とする。\(G_a x=x+E_pa\) と置くと、測定列も指令列も同じなので

\[
\Psi_{k,\theta}(G_a x)=G_a\Psi_{k,\theta}(x).
\]

この等式を微分すると

\[
\boxed{J_{k,\theta}E_p=E_p}
\]

であり、少なくとも三つの固有値が厳密に1になる。三時定数やPID、機体パラメータを変えても、この対称性は消えない。固定された目標に対して真の位置だけがずれるため、これは単なる図の座標原点の移動と同一視できない。

現在の抗力零のモデルでは、真の速度だけをずらしてもIMU列は変わらない。位置・速度の摂動部分の一周期写像は

\[
\begin{bmatrix}\delta p^+\\\delta v^+\end{bmatrix}
=
\begin{bmatrix}I_3&\Delta t I_3\\0&I_3\end{bmatrix}
\begin{bmatrix}\delta p\\\delta v\end{bmatrix}
\]

となり、三つのJordan鎖、合計少なくとも六つの単位固有値を持つ。ただし結論には、抗力に依存しない三つの位置モードの証明だけで十分である。

よって、hover固定点があれば \(\rho\ge1\)。固定点がなければ安定なhoverの事象自体が成立しない。今回の**全拡大状態の厳密な規準**では

\[
\boxed{Q(k)=0\quad\text{for every PID }k}
\]

である。既知の初期位置・初期速度は、雑音のない整合した初期条件の部分集合を選べるが、全状態の固有値規準から推定誤差方向を取り除く理由にはならない。IMUの雑音やバイアスによる積分ドリフトも、絶対位置の帰還情報を生まない。

これは「飛べない」「動けない」「実飛行の失敗確率が1」という主張ではない。初期条件を制限した名目運動、有限時間の誤差・到達、姿勢だけの安定、同値類や部分空間に制限した安定は別の規準である。これらへの変更や単位モードの除去には、ユーザーの明示選択が必要である。

## 図と保存値の意味

今回のゼロは、全格子点で閉ループ行列を数値計算した結果ではなく、上の対称性から得た解析的な証明による。新しいanalytic certificateのschemaで、少なくとも次を区別する。

- `criterion_decided`：上の全状態規準の安定事象が成立しないこと。
- `spectral_radius_lower_bound = 1`：固定点がある場合の構造的下界。実際のスペクトル半径ではない。
- `numeric_evaluated = false`：固有値計算をしていないこと。
- 固定した全N座標・重み・元推定の出自と、入力復号時の数値的な有効／不能数。

未計算の正確な固有値、hoverの存在数、数値的なpole有効数を捏造しない。数値計算した単位モードが丸めで \(1-10^{-14}\) になっても、この既知の厳密な規準で安定とは数えない。

3D図とI=1のP-D図は、この全状態規準のゼロを示す。色の意味は従来の安定割合0〜1を維持する。範囲は各failureの記録ゲインに対する既存の0.25〜2倍とし、成功値を範囲や計算点の選定に使わない。I=1断面はユーザーが指定した正確な面であり、近傍I列や補間によって代用しない。

とくにXY群の記録Iは0.1であり、I=1面には載らない。failure／successの記録点をP-Dへ投影して、その面上で実際の全12ゲイン制御器を評価した点のように表示しない。旧mocap図は上書きせず、今回のIMU-only図と証明・出自を別に保存する。

## 実行結果と再現

`grape-imu-only-pid-20261106` セッションの四ペインで、failure1・failure2それぞれの3DとI=1断面を生成済み。3／5／9／17／33／65の各要求解像度を描画し、3D側は約17.6秒、断面側は約10.8秒で完了した。計算終了後のペインはログ確認用に残している。Gitに保存するのは33・65の結果だけである。

| 入力 | 推力τ [s] | gyro τ [s] | accel τ [s] | 倍精度の正規化機体へ復号可能な座標／全N |
|---|---:|---:|---:|---:|
| failure1 | 0.219004 | 0.037190 | 0.066206 | 64 / 128 |
| failure2 | 0.355210 | 0.061599 | 0.062091 | 67 / 128 |

元の共同Gaussianは非常に広く、有限な対数座標でも指数変換後の機体行列が倍精度で表現できない点がある。共通質量スケールは代数的に相殺してから復号し、それでも不能な点の座標・重み・理由を残す。これを観測器の失敗件数や固有値の評価件数と読み替えない。全域0の証明は全実数の物理対数座標に対して成立するため、復号可能な部分への条件付けも、この128点による求積も必要としない。

33・65は既存の記録ゲインanchorを挿入する前の要求格子数である。実際の各軸長は保存した `p_axis/i_axis/d_axis` を正とし、I=1断面は常にI軸長1とする。128個の決定論的Sobol由来座標は入力の追跡・数値診断用に保持したものであり、モンテカルロではなく、今回のゼロの証明を有限点近似したものでもない。
