# 取得頻度2 Hz・5 Hzと角速度ノイズの比較

2026-11-13。ユーザーの訂正に従い2 Hzと5 Hzを別条件で計算し、0.5 Hzを対照として残した。角速度ノイズの「2.5」は標準偏差2.5 deg/sであることを確認した。比較用に0.1、0.5、1、2、2.5、5 deg/sを設定し、周波数3種類×ノイズ6種類を別ファイルに保存する。

[全18条件のPDF一覧・数値](publication/bag8_rate_noise_sweep/INDEX.md)、[σ=2.5 deg/sの周波数比較図](publication/bag8_rate_noise_sweep/rate_overview_sigma_2p5.pdf)、[全数値CSV](publication/bag8_rate_noise_sweep/comparison_table.csv)。

## 同じ入力を使った周波数比較

一日目#8の同じ5秒区間、同じ一度だけのmocap初期姿勢を使う。原ジャイロ列のbag時刻50秒を起点として、要求する取得時刻以降の最初の原header標本を選んだ。値を補間して架空の測定を作らず、source index、原header ns、record nsを保存する。

| 取得頻度 | 間隔 | 5秒間の観測数 |
|---:|---:|---:|
| 0.5 Hz | 2秒 | 3 |
| 2 Hz | 0.5秒 | 10 |
| 5 Hz | 0.2秒 | 25 |

0.5 Hzの取得標本は前回と完全に同じ。公称慣性、別記録由来の固定推力時定数、ロータ入力・実測gimbal、過去40〜45秒だけから求めた固定余剰トルク平均は、[前回の保存入力](../publication/bag8_50_55s/)からそのまま再利用した。再同定・トルクの合わせ直し・時刻補正はしていない。取得されなかったジャイロ値や途中mocap姿勢は予測に入れない。

各取得で \(\mathcal N(\bar\omega_k,\sigma^2I_3)\) の同じ6点則を使う。σは1測定あたりの標準偏差でありPSDではない。新しい入力と現在の姿勢候補の独立性は前回と同じ仮定。区間内部では同じ6本を角速度・四元数の同時運動方程式で積分する。測定値に乱数ノイズを追加していない。

独立な観測誤差という仮定では、小角度で角度分散は \(\sigma^2\sum_k\Delta t_k^2\) に比例する。σ=2.5 deg/sなら終端2σ幅の目安は0.5 Hzで15度、2 Hzで約7.91度、5 Hzで5度。共有バイアスや時系列相関に同じ低減を主張しない。

## 候補法則を変えずに指数的な列挙を避ける

以前はRPYの平均・共分散を得るために6³=216個の積を列挙した。5 Hzでは6²⁵となるため、今回は6点増分の**因子列そのものを保持**し、同じ有限積法則の四元数二次モーメントと回転行列の平均・全9×9共分散を伝播する。Monte Carlo、枝の削除、Binghamへの再近似、共分散floorは使わない。coreは変更しない。

列優先 \(\operatorname{vec}R\) の平均・共分散を \(m,C\)、今回の6点増分の回転を \(D_s\)、\(A_s=D_s^\top\otimes I_3\) とすると、

\[
m'=\sum_s w_sA_sm,\qquad
C'=\sum_s w_s A_sCA_s^\top
 +\sum_s w_s(A_sm-m')(A_sm-m')^\top.
\]

これは同じ独立な有限求積法則について、全交差を残した厳密な回転成分モーメント再帰である。6点による非線形Gaussian積分とRK4・補間の近似は前回同様に残る。区間開始の法則を固定し、中間時刻では区間開始からの全増分を一度合成する。

RPYの中心・帯だけは、同じ回転モーメントに対するdelta-method表示近似とした。

\[
\text{RPY中心}=f(E[R]),\qquad
C_{\rm RPY}\simeq Df(E[R])\,C\,Df(E[R])^\top.
\]

これは \(E[\mathrm{RPY}]\) の厳密計算ではない。\(E[R]\)を回転行列へ投影する処理や、表示用に別の分布を作る処理は行わない。この近似表示を状態へ戻さず、全周波数・全ノイズで同じ表示法を使った。帯は局所的な±2σで、Gaussian・95%被覆の保証ではない。

σ=2.5 deg/s・0.5 Hzで旧216点列挙と照合した結果、四元数二次モーメントは完全一致し、回転平均の差は最大 \(1.78\times10^{-15}\)、全回転共分散の差は \(4.51\times10^{-17}\) だった。一方、非線形法のRPY中心には最大0.129度、2σ幅には最大0.163度の表示近似差がある。[検算数値](publication/bag8_rate_noise_sweep/display_approximation_audit.json)を保存した。

全周波数の誤差を共通の501時刻で比較し、観測イベント数の差によってRMSEの時間重みを変えない。0.02秒間隔と実観測時刻で得た表示統計を共通時刻へ線形補間している。RK4最大刻みは2 msで共通である。

## 結果

σ=2.5 deg/sのSO(3)姿勢RMSEは次のとおり。比較する中心は上記のRPYモーメント近似から作っている。

| 取得頻度 | 一定角速度 [deg] | 線形強制 [deg] | 非線形 [deg] |
|---:|---:|---:|---:|
| 0.5 Hz | 12.507 | 108.729 | 108.589 |
| 2 Hz | 4.650 | 50.981 | 50.980 |
| 5 Hz | **1.768** | 21.707 | **21.660** |

5 Hzの非線形法の終端2σ幅はRPYの順に約(5.028, 4.993, 5.038)度。周波数を上げることで区間中の取り逃しと誤差の蓄積は減るが、公称入力トルクモデルと実測角運動の不整合は残っている。ノイズを広げただけでこの平均のずれが直るとは扱わない。

0.5 Hzの前回公開図は変更していない。今回の0.5 Hzはσ=2.5を明示的に含む新比較で、RPY表示法・RMSEの共通時刻も全周波数に揃え直している。

## SG由来角速度による別の周波数対照

[別のSG診断PDF](publication/bag8_rate_noise_sweep/sg_diagnostic/sg_benchmark.pdf)では、同じmocapからSG窓0.32秒で得た角速度を各周波数で取得・保持した。力学モデル・制御トルク・ノイズ分散の伝播は使わない。

| 入力 | SO(3) RMSE [deg] |
|---|---:|
| 全レートSG曲線 | 0.231 |
| 0.5 Hz取得・保持 | 10.719 |
| 2 Hz取得・保持 | 5.963 |
| 5 Hz取得・保持 | **1.566** |

これは同じmocapからの微分・再積分の運動学的な診断であり、独立IMU推定の精度ではない。0.5／2／5 Hzそれぞれの数値ファイルも分けて保存した。SG診断の取得時刻は開始から正確な0.2／0.5／2秒間隔、実gyro比較は原header標本という違いを保存metadataに記録する。

## 再現と保存

公開先は `publication/bag8_rate_noise_sweep/`。全18条件の各方式について、四元数二次モーメント・回転平均・全共分散・増分因子と、図を描いた同じ配列を保存する。元の小容量入力・トルクは既にGitにある親ディレクトリの公開入力を再利用し、hashを記録する。生bag・動画・一時キャッシュを追加しない。

```bash
env PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  MPLCONFIGDIR=/tmp/grape5hz-mpl /usr/bin/python3 \
  ros/examples/grape-param-estim/minimal/nonlinear-gyro-dead-reckoning/rate_comparison_5hz/run.py \
  --rates 0.5 2 5 --sigmas 0.1 0.5 1 2 2.5 5 --output /tmp/grape5hz-rerun
```

SG対照は同フォルダの `sg_benchmark.py`、選別保存は `publish.py <計算親ディレクトリ> <新しい公開先>`。既知解、元標本の選択・時計、同じ評価分母、全積法則とのモーメント一致、未取得gyro／途中mocapの非使用を検証した。
