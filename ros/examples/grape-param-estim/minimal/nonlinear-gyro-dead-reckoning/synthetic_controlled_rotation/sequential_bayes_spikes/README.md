# スパイク入りgyro：非線形モデルとジャイロ項なしの比較

[現在の図・動画・数値](frequent_publication/INDEX.md) ／ [数式と再現手順](FREQUENT_SPIKES.md)。

両モデルに同じスパイク入りgyro、原時刻、初期候補、慣性、入力トルクを与える。比較の違いは角速度方程式の `omega cross(J omega)` 項だけで、四元数の運動学と時系列Bayes更新は共通である。

現在の人工運動は、実飛行#8の40〜60秒から求めたbody角速度の周波数と強さに合わせている。各軸の角速度標準偏差を実測mocapのSG微分値の1.5倍、約`[4.38,12.46,5.27] deg/s`とし、3周波数の滑らかな合成姿勢からgyro・角加速度・入力トルクを生成し直す。実飛行の時間波形を再生したものではなく、運動の統計的な規模を合わせた試験である。[校正値・出自](flight_motion/calibration.json)と[実飛行との比較図](flight_motion/comparison.pdf)を保存した。

20秒、更新1 Hz、生測定200 Hz、生成白色σ=2 deg/s。最初15秒にPoisson 10 Hzのスパイクを加え、最後5秒にも正常な観測更新を続ける。運動の校正に合わせてセンサ雑音や推定共分散を調整しない。方位と角速度の同じ共同候補、全共分散と交差を保持し、角速度にも保存値の±2σを表示する。

白色ノイズのみの比較図・数値、旧単発比較の出力は削除した。現在のフォルダへ二モデルの結果を上書きする。`run.py`は共通の評価関数を保持し、直接実行した場合も現在の`frequent_run.py`へ進む。
