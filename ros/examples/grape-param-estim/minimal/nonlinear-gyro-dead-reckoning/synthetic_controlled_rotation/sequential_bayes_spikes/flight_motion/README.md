# 実飛行の運動スケールに合わせた合成回転

このディレクトリは、合成軌道の振幅・周波数を実飛行から決めるための参照計算である。推定結果を見て条件を選び直していない。合成軌道のパラメータは、フィルタを実行する前に `flight_motion_profile.json` へ固定する。実飛行の再現推定ではなく、実飛行に近い運動スケールを持つ滑らかな既知入力の試験である。

## 参照したデータ

一日目 #8、`20260612_grape_hovering_8_2026-06-12-17-46-41.bag` の bag 開始後40–60秒を用いた。既存の独立した SG 検査が保存していた39.5–60.5秒の入力を読み、今回の結果を理由に区間を選び直していない。`/gimbalrotor/imu` の `gyro` は body/FC 座標の rad/s、`/gimbalrotor/mocap/pose` の quaternion は body→world の Hamilton 四元数である。元のheader/record ns、source indexは `comparison.npz` に保存し、完全な元入力のパスとSHA-256は `calibration.json` に記録した。bag自体は複製していない。

実測gyroは200 Hz、mocapは120 Hz。mocapの世界Zはこの区間で平均0.8473 m、範囲0.7657–0.8808 mであり、既存の初期0–8.5秒の平均0.2454 mから約0.602 m上がっている。これは高度を維持していたことの確認であり、全状態の漸近安定性の証明ではない。

角速度の運動成分には、既存の中心0.32秒・3次多項式SGで四元数を微分したbody角速度を使った。四元数正規化の微分を含め、`omega = 2 vec(conj(q) Hamilton qdot)` としている。RPYの微分をそのままgyroとして扱っていない。これはオフラインの参照処理であり、生gyroや推定状態を平滑化・置換する処理ではない。

| body軸 | 生gyro標準偏差 [deg/s] | mocap-SG標準偏差 [deg/s] | 合成目標＝SGの1.5倍 [deg/s] | 新合成の最大絶対値 [deg/s] |
|---|---:|---:|---:|---:|
| x | 2.789 | 2.920 | 4.380 | 10.287 |
| y | 7.839 | 8.306 | 12.458 | 27.640 |
| z | 3.427 | 3.512 | 5.269 | 11.539 |

1.5倍は「実飛行より多少強い擾乱でもよい」という指定を、運動の各軸の標準偏差へ適用した固定倍率である。測定ノイズや推定共分散の倍率ではない。

## 周波数と振幅の決め方

1. 20秒のbody角速度を、スペクトル計算のためだけに120 Hzの等間隔時計へ線形補間する。線形トレンドを除き、Hann窓のperiodogramを計算する。周波数分解能は0.05 Hz。
2. 0.05–3 Hzの範囲で、0.10 Hz以上離れた局所最大値を強い順に三つ選ぶ。この帯域には実飛行SG角速度の約96–99%のパワーがあり、振動・測定ノイズの高周波を運動周波数と読み替えないために分けている。これは有限区間のスペクトルピークであり、機体の固有モードを同定したという意味ではない。
3. その周波数を固定し、各RPYに対して定数項と三組のsin/cosを通常の最小二乗で当てはめる。係数から振幅・位相・平均姿勢を得る。
4. RPY三軸の振幅全体へそれぞれ正の倍率を掛ける。正確な `Rz(yaw) Ry(pitch) Rx(roll)` のbody角速度式で評価し、三軸の標準偏差が参照値の1.5倍になるように三変数の最小二乗を解く。周波数と位相は変えない。

選定周波数は、roll側が **0.25, 0.10, 1.30 Hz**、pitch側が **0.75, 0.90, 0.60 Hz**、yaw側が **0.25, 0.45, 0.75 Hz** である。角度のPSDではなく、body角速度のPSDから選んだため、小振幅の角度でも速度に現れる成分を残せる。

三つの大域的正弦波は、非定常な実飛行の全成分を表せない。倍率適用前のbody角速度の分散説明率はx約22%、y約39%、z約35%である。yawの第三成分は実測PSDでは意味のあるピークだが、20秒全体の一定振幅・位相による最小二乗では小さくなる。三成分を大きく見せるための人工的な成分追加は行っていない。全波形を一致させたとは主張しない。

## 試験へ渡すものと渡さないもの

`flight_motion_profile.json` は**生成側だけ**が読む。そこから合成gyro真値と、既知トルク `tau = J alpha + omega cross(J omega)` を再計算する。推定側へ渡すのは、従来どおり既知のJ・保存されたトルク・最初の姿勢・1 Hzで取得した同じノイズ入りgyroだけである。途中のmocap・合成真値・白色ノイズの実現値・スパイクフラグは推定に使わない。

白色ノイズの生成標準偏差2 deg/s、仮定する観測標準偏差5 deg/s、Poisson開始のスパイク、1 Hz更新、20秒、最後5秒の回復区間は変えない。推定の比較は、同じスパイク入り測定を受ける非線形Eulerと、`omega cross(J omega)` だけを省いたモデルの二つである。

## 出力と再現

- `comparison.png` / `comparison.pdf`：上段に実飛行と新合成のbody角速度、中段に旧合成との同単位比較、下段に三者のPSD。元の保存数値を描き、推定を再実行していない。
- `comparison.npz`：実測の原時計・元index・gyro・mocap、参照SG結果、旧／新合成のRPY・body角速度、PSD。分布推定や共分散を含まない校正用の数値。
- `calibration.json`：出典・単位・時計・統計・周波数選定・近似の限界・校正残差・source hash。
- `flight_motion_profile.json`：固定した生成パラメータ。
- `calibrate.py`：上の全出力を再生成する。乱数やフィルタ出力を使わない。

```bash
/usr/bin/python3 ros/examples/grape-param-estim/minimal/nonlinear-gyro-dead-reckoning/synthetic_controlled_rotation/sequential_bayes_spikes/flight_motion/calibrate.py
```
