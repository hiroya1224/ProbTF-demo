# Bayes Factor Surpriseと身体変化仮説

2026年10月17日のユーザー指示を記録する。既存の身体候補が新観測に対して過信状態になっている問題に対し、下記論文に基づく変化仮説を追加する。指定された変化事前確率は25%である。本書は論文に由来する式と、このデモの状態・観測・近似に合わせて置く実装仕様を区別する。末尾に実装の整合性検証と実姿勢の精度を記録する。実配信で身体姿勢の過信は残存しており、到達も未達だった。

## 論文と25%の意味

Vasiliki Liakoni, Alireza Modirshanechi, Wulfram Gerstner, Johanni Brea,
“Learning in Volatile Environments With the Bayes Factor Surprise,”
*Neural Computation* 33, 269–340 (2021).
[DOI: 10.1162/neco_a_01352](https://doi.org/10.1162/neco_a_01352)。
[著者公開PDF](https://lcnwww.epfl.ch/gerstner/PUBLICATIONS/Liakoni21NeuralComputation.pdf)。

論文では、未知パラメータを保持する場合と初期事前から引き直す場合を比較する。新観測の予測evidenceをそれぞれ `E_keep`、`E_reset` とすると、Bayes factorと変化事後質量は次のとおりである（pp.274–275、式(2.6)–(2.10)）。

\[
S_{\rm BF}=\frac{E_{\rm reset}}{E_{\rm keep}},\qquad
m=\frac{p_c}{1-p_c},\qquad
\gamma=\frac{mS_{\rm BF}}{1+mS_{\rm BF}}.
\]

両事前を同じ新観測でBayes更新した事後を `pi_keep+`、`pi_reset+` とすれば、更新結果は次の算術mixtureである（p.275、式(2.10)–(2.12)）。

\[
\pi^+=(1-\gamma)\pi_{\rm keep}^++\gamma\pi_{\rm reset}^+.
\]

今回の指定 `p_c=0.25` は変化仮説の事前確率で、事前oddsは `m=1/3` となる。`gamma` は、その明示した変化モデルの下での事後確率である。すべての仮定が正しいかどうか、物理世界の到達成功、センサの外れ値を直接判定する確率ではない。

| 同じ新観測のevidence比 `S_BF` | 変化事後質量 `gamma` |
| ---: | ---: |
| 1 | 0.25 |
| 3 | 0.50 |
| 9 | 0.75 |

論文のVarSMiLeは事後密度の**対数**を補間する別の近似である（pp.277–278、式(2.13)–(2.15)）。今回採用する算術mixtureのモーメント合成をVarSMiLeと呼ばない。

## このデモで何が変化するのか

以下はデモの仕様として置くモデルであり、論文がロボットの状態・目標記憶を直接定義しているわけではない。

身体の全局所変換を `B`、未知の根元マーカー配置を `E` とする。前回の単一内部代理を、前周期に凍結した推定Kの同じ指令作用で現在の送信指令 `q` へ運んだ全共同分布を `rho_keep(B,E | q)` と書く。保持仮説はこれを使う。

reset仮説は、身体だけに対する変化kernelを使う。

\[
\rho_{\rm reset}(B,E\mid q)
=\rho_{B,\mathrm{direct}}^{(0)}(B\mid q)
\,\rho_{{\rm keep},E}(E).
\]

`rho_B,direct^(0)` は既に設定されている直接指定初期Gaussian・Bingham候補族を、現在の送信指令で評価したものである。真の関節角・たわみ・剛性から作らない。既知の工具・カメラ取付のDirac部分もそのまま使う。未知マーカー配置はkeepの周辺を保持し、初期マーカー配置へ戻さない。reset仮説内では身体が保持環境から独立になることを、kernelの一部として明示する。全共同事後の交差を説明なく消す操作とは区別する。

変化前の遷移事前は、`0.75 rho_keep + 0.25 rho_reset` である。保持仮説を毎周期破棄する処理でも、全身体へ常に分散を加算する処理でもない。新観測が保持仮説に整合すれば、そのevidenceがreset仮説を抑える。reset仮説が相対的によく観測を説明すれば、観測で更新されたreset側の質量が増える。

剛性モデルは、keepを現在指令へ運ぶ既存の凍結補正と、後述の補助密度比で使う。reset身体を推定Kや真のKから作り直さない。

25%はこの身体候補の変化kernelに対する値である。剛性Kや固定スイッチが物理的に変化する確率へ読み替えず、Kの保持密度を初期事前へ戻す処理も追加しない。

## 25%を適用する時刻

`p_c` の単位は、一つ以上の**新しい有効観測**を取り込む時刻である。IMUと画像が同時に有効でも変化変数は一つとし、25%をセンサごとに二重適用しない。この値は毎秒25%という連続時間hazardではない。有効観測頻度が違えば、単位時間当たりに比較する回数も変わる。

| 入力 | 変化仮説の扱い |
| --- | --- |
| 新しい有効IMUのみ | 共通の二仮説を一度更新 |
| 新しく検出したマーカーのみ | 全画像候補で二仮説を一度更新 |
| 同時刻の新しいIMU＋マーカー | 同じ変化変数と全観測を一度融合 |
| 画像未検出だが新しいIMUあり | IMUで更新し、記録済み根元目標を保持 |
| 全観測欠落・no sensor | 変化の時計を進めず、予測した内部分布を恒等保持 |
| 同じ観測の再送・RVizの再表示 | 再適用しない |

有効なマーカー観測は、検出器の新しい有効結果とそのセンサ事後がある場合に限る。画像を得られなかったこと自体の尤度は、このデモでは新たに導入しない。無観測時のBayes factorや変化事後確率を、計算済みの0として記録しない。

## evidence、融合、保持するmixture

両仮説に対して、同じ観測集合・観測モデル・観測側の候補質量と積分測度を使う。各センサはそれぞれの親事前から局所事後を構成し、既存coreの成分対応と共通事前補正を含む融合へ渡す。センサが共有する身体を通じて依存が生じるため、IMUの周辺evidenceと画像の周辺evidenceの積を、全観測のevidenceに置き換えない。融合時の正規化項と親ごとの事後質量から、全観測の `log E_keep`、`log E_reset` と `gamma` を求める。

IMUでは、観測した重力方向を基準に同じ2次元接平面を両仮説へ使う。親事前のmodeごとに別々の接平面を選んだ密度は、そのまま比較しない。画像には既存の画像Hessian由来Laplace候補と座標体積補正を使う。ここでのevidenceは、これらの正規化された局所Gaussian観測代理に対する積分であり、球面全域の厳密なIMU尤度や生画素の厳密尤度を新たに実装したものではない。大きな角度差での接平面・一次近似の精度まで保証しない。

数値計算はlog領域で行う。

\[
\log S_{\rm BF}=\log E_{\rm reset}-\log E_{\rm keep},\qquad
\gamma=\operatorname{sigmoid}(\log S_{\rm BF}-\log3).
\]

reset親の全枝のlog massをlog-sum-expで合計した事後質量も、同じ `gamma` となる。小さなfloat weightのunderflowを、有限log weightを持つ枝の削除理由にしない。両evidenceがともに非常に小さい場合もあるので、BFだけでなく両log-evidenceを残す。

新しい画像の全候補は、keep/resetの両親で更新・融合する。新しいマーカー観測から比較用目標を作るときは、各仮説・観測枝のマーカー条件付き候補を、共通の内部身体周辺の下で構成する。すべての枝・重み・log weightをIKの `p_goal` と表示へ渡す。最大重み枝、平均目標、成分ごとの対数平均へ置き換えない。

二つの仮説は確率的に一方をdrawして選ぶものではない。両方を決定論的に計算する。観測・仮説mixtureと、描画のための同じ分布への点照会は別物である。

## 単一内部代理への近似と座標

ユーザーは追加訂正で、Bayes surpriseにより不定座標変換側に生じる和をmoment matching等で一つにまとめてよいと明示した。以下の縮約はこの許可を適用するものであり、新しいマーカー観測と規準に用いる `p_goal` のmixtureは別に保持する。

融合後の各枝は、その親の凍結Bingham由来座標で全共同Gaussian代理として記述される。親が違う座標の数値配列を、そのまま同じ座標だとみなして足さない。既存の高集中一次表現に対応する明示的な座標輸送を全平均・全共分散と全交差ブロックへ作用させ、一つの参照座標へ揃える。

同じ座標へ輸送した全枝の平均・共分散・正規化質量を `mu_i, P_i, w_i` とすれば、内部代理のモーメントは、

\[
\bar\mu=\sum_iw_i\mu_i,\qquad
P=\underbrace{\sum_iw_iP_i}_{\text{within}}
+\underbrace{\sum_iw_i(\mu_i-\bar\mu)(\mu_i-\bar\mu)^\top}_{\text{between}}
\]

とする。身体と未知マーカーを含む全共同ブロックに対して計算し、既存coreで一括再表現する。内部状態はこの一つだけを次周期へ持ち越し、過去の全仮説・画像候補の直積を列挙し続けない。方位の代理は供給されたBinghamのS²への作用から導いた既存の高集中近似であり、別にSE(3)上のGaussianを仮定する変更ではない。

論文の二仮説Bayes式を用いた後、この一次座標輸送・モーメント縮約・Bingham再表現を行うのが今回の近似である。正確な群上の全履歴Bayes事後や、厳密なBinghamモーメント整合を行ったとは説明しない。共分散の支持・PSDと既存の一次適用域を検査し、域外をjitter、固有値floor、分散縮小で隠さない。

単一化後の同じ分布オブジェクトと、対応する全目標mixtureを推定結果・IK・表示・次指令への伝播へ渡す。表示専用に広げたり、シミュレータの実身体へ再中心化したりしない。

## 画像欠落中の固定目標と交差共分散

記録済み目標の根元周辺、全成分の混合質量・log weight、取得時刻・指令・版は保持する。ここでのresetは、記録済みのスイッチが物理世界で動いたという仮説ではない。

各旧目標成分について、keep仮説では従来のSchmidt近似で身体だけを観測更新する。予測身体共分散を `P_keep0`、keepの観測後共分散を `P_keep+`、予測交差を `C_old` とすれば、支持上で、

\[
C_{\rm keep}^+=P_{\rm keep}^+P_{\rm keep0}^{\dagger}C_{\rm old}
\]

とする。`dagger` はMoore–Penrose逆行列、上付き `+` は観測後を表す。reset仮説の身体は保持目標から独立と宣言しているので、その仮説の交差は0である。両仮説で目標の平均と `P_EE` は同じ保持値にする。

keep側交差を共通座標へ運び、単一内部身体へ再表現する全輸送を `J` と書けば、合成した交差は、

\[
C_{\rm mix}=(1-\gamma)J C_{\rm keep}^+
\]

となる。身体の周辺共分散には両仮説のwithinとbetweenを含めるが、目標平均が両仮説で同じなので、身体・目標間にbetween由来の項は加わらない。各仮説の同じ目標周辺を持つ共同代理を混合したモーメントとして構成し、共同PSDを確認する。

混合後の身体共分散はkeep事前より大きくなる場合がある。この拡大した値を、収縮を前提とする旧 `P_post P_prior^+ C` へそのまま代入しない。keepの収縮とresetの零交差を先に扱うことが必要である。この処理は固定環境を条件付けないcut／Schmidt近似を含み、完全な環境Bayes事後とは説明しない。

新しいマーカー観測を得たときは、全観測枝を通常の融合へ入力し、同じ推定カメラ・全マーカー候補から目標mixtureと取得元記録を更新する。マーカー喪失時の減速・静止・有限探索、探索軌跡のオレンジ表示は従来のまま使う。

## 剛性記憶との接続

剛性の補助密度比は、実際に使った遷移事前に対する観測更新を記録する。分母には `0.75 rho_keep + 0.25 rho_reset` の身体周辺、分子にはIK・表示と同じ単一化後の身体代理を用いる。未知マーカーを周辺化し、全身体共分散と仮説質量を使い、異なる参照座標を共通測度へ照会する体積係数も保つ。

分母をkeepだけにすると、明示kernelによる事前変更まで観測由来の情報として剛性へ追加してしまう。新しい分母と分子のsource ID、時刻・送信指令・版・全質量を記録する。分子は指定された内部モーメント近似を含むため、この比を元の厳密観測尤度そのものと呼ばない。

無観測の周期では新しい比因子を追加しない。真の剛性は入力せず、現在の保持身体をKから再生成しない。既存の同じ凍結Kによる選定分布と次事前の一致を維持する。

身体内部状態のサイズと一周期に比較する変化仮説数は一定だが、剛性密度は従来どおり累積因子を保持する。デモ全体の計算時間・記憶量が観測数によらず一定になったとは主張しない。

## 変更範囲と検証条件

この明示kernelの範囲に限り、従来の「初期身体分布の生成は開始時だけ」「分散回復・独立化を一切追加しない」という規定を更新する。説明のない過程雑音・任意分散回復・観測欠落による初期化を許す変更ではない。coreの既定法則、RViz設定、点径・画像サイズ・レイアウトは変更しない。

少なくとも次の内容を数値と実公開データで検証する。

- 25%の事前質量、odds 1/3、正規化evidence、BF、親事後質量、全観測共通補正の対応。
- 同じ新観測での二仮説更新、全画像枝・有限log weightの保持、全共同within・betweenと座標輸送。
- 全欠測・再送時の非適用、未知マーカー周辺のreset保持、画像欠落時の固定目標と正当な交差・共同PSD。
- 剛性比の実遷移事前分母、IK・表示と同じ事後分子、同じ凍結Kでの選定分布と次事前。
- 実際のsnapshot・分布表示・目標mixture・剛性公開値のsource ID、時刻・指令・版・全パラメータの同一性。
- マーカー停止・探索・再検出の既存動作、実軌跡の色対応、RViz設定のバイト一致。

保持分布が不正確である原因が、可観測性の欠如、観測モデルの系統誤差、近似の適用域外にある場合、この変更だけで真の各リンク姿勢を識別できるとは限らない。BF更新の整合性、推定値と実物理の誤差、分布の幅、到達・干渉の物理条件は別に評価する。既存の過信を解消したという結論には、変更後の数値結果が必要である。

## 検証結果（2026年10月17日）

共通の回帰テスト313件のうち311件が一括実行で通過し、残る旧仕様の期待値2件を二つの遷移事前と単一分子の仕様へ更新して、対象2件も通過した。新規テストには、相関する2センサのjoint evidenceと解析的Bayes factor、原分布の出自、全交差の座標輸送・within＋between、分散拡大時の固定目標とPSD、実際の剛性密度比、実ROS表示との一致を含む。初期packetで両仮説が同じ場合の `gamma=0.25`、強いIMU不一致で変化事後質量が0.9を超えて共分散が広がる場合、全欠測での厳密恒等も確認した。

headlessでは、同じ実 `MotionSession` をIMU単独121周期・6シミュレーション秒、no sensorを31周期・1.5秒動かした。IMUの全121周期でBFと剛性の新因子を更新し、同じK作用による選定分布と次事前を120回、推定・制御・serialized ROS表示を121周期照合した。no sensorではBFを全周期 `null` とし、身体・剛性の恒等保持と直接指令作用による次事前30回の一致を確認した。いずれも到達は未達、禁止干渉はなかった。

IMU単独の終端で、手先の絶対位置誤差は49.574 mm、`sqrt(trace(P))` は71.402 mmだった。しかし異方性を含むMahalanobis二乗は9.243で、3次元95%楕円体の閾値7.815を超える。この軌道の95%楕円体内は6/121時刻だった。リンク3は誤差43.557 mm、`sqrt(trace(P))` が16.676 mm、Mahalanobis二乗16.382で、95%内は0/121時刻だった。単に分布のtraceが広がったことを、実誤差を説明できた証拠とは扱わない。これらは同じ軌道の時刻集計であり、独立反復による校正試験ではない。

## 実配信の最終結果（2026年10月17日）

マーカー単独とIMU併用を、同じ物理世界・事前・設定で各30シミュレーション秒・601周期動かした。snapshot、分布MarkerArrayの実wire、剛性、motion metadata、scene MarkerArrayの実wireを受信し、計1202周期を照合した。実装の詳細な結果・全source hash・各リンクの誤差・全目標成分は [最終検証記録](validation/bayes_factor_surprise_20261017.json) に保存した。

実公開された分布に対し、82,938件のcore点照会と描画点、662回の二つのnative priorからのセンサ融合・正規化joint evidence・座標輸送・全共同within＋betweenを再計算した。IMUだけが有効で画像が欠落した44周期では、keep側Schmidt交差とreset側零交差の合成、固定根元目標の周辺・質量・取得元の保持を確認した。1200回の選定指令について同じ凍結Kでの次事前を照合し、全周期で公開BF辞書、内部身体、全目標mixtureと剛性比分母・分子の出自を確認した。別の表示用分布は作っていない。313件のテストが通過し、coreの既定法則とRViz設定は変更していない。
