# 観測で身体候補を保持・更新するスイッチ到達デモ

2026年10月19日の最新変更は[手先姿勢に対するK推定](HAND_POSE_STIFFNESS_20261019.md)。K候補の準静的予測を、共同身体候補から棒先端まで伝播した位置・方位の観測前後分布比で評価する。途中リンクの個別一致度はK規準へ加えず、全crossは手先伝播に保持する。真値注入は以前の診断harnessを含め撤回し、過去の介入結果は履歴資料として区別する。

初期表示は[観測前の剛体事前分布](INITIAL_PRIOR.md)。async起動時は初回joint通知だけで同じ推定・制御・表示lawを構成し、`autostart=false`では画像・IMUを保存しながら観測融合を開始操作まで保留する。最初の観測後の事後を、観測前の初期分布として表示しない。

推定の現行方式は[伝播モーメントの逆微分によるGaussian変分更新](VARIATIONAL_MOMENT_UPDATE.md)。各観測の原時刻・実指令で、前回から保持した共同事前を固定し、KL項と観測の期待負対数尤度から共同Gaussianの平均・全共分散を求める。既存の高集中Bingham由来の伝播式と全crossをデモ内C++で逆微分し、同じ観測を反復融合しない。同じcanonical事後を次事前・K比・制御・表示へ渡す。coreの伝播式とRViz設定を維持し、高集中の数値閾値は最新指示に従って撤去した。

取得済みfrontierの処理は[C++による原取得順の逐次更新](CPP_SEQUENTIAL_INFERENCE.md)であり、batchは受渡し単位である。全rawを保存し、処理能力に届かない場合は設定済みの時間被覆選択と未融合理由を明示する。各観測へ実指令ledgerで輸送し、一件ずつ全native/Keep/Reset枝の更新とcanonical化を行う。[共同バッチ推定](BATCH_INFERENCE.md)と以下の過去の数値は撤回済みの比較履歴である。処理率・融合率・未完了件数を取得率と分けて記録する。

全処理に共通する最新規則は[数値監査と早期終了の扱い](NUMERICAL_DIAGNOSTICS.md)。有限な計算結果を残差・精度の独自監査で止めず、未達を診断として残して後続更新へ進む。以下の旧実行で発生したevidence停止の原因と、その後の修正・再検証を区別して記録する。

## 身体の逐次推論

初期分布は `independent_transform_laws.yaml` の直接指定Gaussian・Binghamと未知マーカーの分布から作る。例示用の入力であり、真のたわみから作った較正値ではない。既知の棒・カメラ取付はDirac変換である。

現在指令cから次指令qへ、指定済みの `right_joint_action` を同じ候補に作用させる。2026年10月17日の追加指示により、観測でKを得た周期は、回転量を `q-c` から `theta_eq(q,K)-theta_eq(c,K)` へ変更する。Kと平衡枝は一周期固定する。右回転座標の輸送をGと書けば、全共同共分散も `P(q)=G P(c) G^T` とする。マーカーは同じ時間共有変量として保持し、身体との相関も残す。新たな過程雑音・分散回復・剛性モデルによる身体再生成は加えない。

    初期の直接指定候補族（一度だけ）
        ↓
    前回の単一内部代理を全交差共分散ごと次指令へ伝播
        ↓
    同じ事前から各センサが個別に推定
        ↓
    共通事前を補正して全観測成分を後段融合
        ↓
    全モーメントから内部代理1つと明示的な目標mixtureを構成
        ├─ 同じ身体代理と目標mixtureをIK・core照会・表示に使用
        ├─ 同じ身体代理の事前・事後密度比を剛性記憶へ追加
        └─ 次の短い指令を選定 → 実行 → 次の観測

IMUはlink_3の重力方向に対する2座標の局所事後を返す。yawや並進を観測したことにはしない。カメラは実画像のAprilTag検出・姿勢Hessianから全画像候補を返す。未知マーカーの真の根元姿勢を代入しない。画像だけの検出・Hessian計算は観測ごとに一度行い、全事前成分で共有する。

観測evidenceと画像枝kの条件付き質量から、全体のセンサ事後質量を計算する。既存coreの `fuse_labelled_sensor_posteriors` が、同じ親事前を基準に重複を除いて融合する。ライブ実行の親事前は毎周期一つなので、その凍結chartで全モーメントを計算する。異なる親chartを同じ座標とみなしてGaussianを足さない。

全交差共分散・成分対応・log weightを保存する。通常のfloat weightがunderflowしても、有限のlog weightを持つ正の成分を削除しない。空観測や画像未検出は保持した同時分布への恒等更新である。

**過去の画像候補の全組合せを列挙する旧ライブ実装は撤回した。** ユーザーの明示指示に従い、内部状態は解析モーメントで単一化する。全観測成分を処理してから行う指定近似であり、小さい枝の削除や検出器での単一解選定ではない。比較用目標の全成分・重みはIKと表示へ残す。

## 第4・7章の近似とcore

BinghamをS²へ押し出したベクトル作用の高集中一次代理を使う。共分散は全体O(P)までとし、平均の収縮と相関由来の平均補正を残す。モードFKへ最後に分散を付ける処理ではない。

- `point_query / direction_query / pose_query`: 同じ共同候補の経路作用と全交差ブロックを保持する解析照会。
- `conditional_total_covariance / lift_sensor_posterior`: 条件付き共分散の平均と、条件付き平均の共分散を実際に計算する。
- `gaussian_reference_product / fuse_labelled_sensor_posteriors`: 共通事前を補正した成分対応付き融合。
- `reexpress_state`: 各事後成分の同時再表現。全交差ブロックを保持する。
- `covariance_support`: 支持上で計算する。exact-zeroの既知固定座標は固有分解から分離し、Dirac取付へ数値丸めの偽分散を入れない。jitter・固有値floorを使わない。

一次APIの適用域は `lambda_max(C_A) <= 0.1 rad²`。適用域外を分布の縮小や別バックエンドで隠さない。これは近似の適用域であり全条件での誤差保証ではない。

## 剛性の補助記憶と指令提案

逐次内部状態は一つの共同代理とする。現在の観測mixtureを全てセンサ別更新・後段融合へ入力した後、同じ凍結chartで全平均と全共分散を求める。成分内分散と成分間平均の分散をともに含め、既存coreでBinghamへ一括再表現する。未知マーカー配置との交差ブロックも保持し、次指令への作用を通す。過去の観測候補の全組合せは列挙しない。

同じ新観測の身体事前と、この指定された内部近似後の事後を、同じ凍結chartで受け取る。未知マーカーを周辺化し、6リンクの36次元全共分散を使う。密度比は指定されたモーメント近似を含む比であり、縮約前の厳密な観測尤度そのものとは呼ばない。

    ell_t(K) = log p_X,t+(Phi_u,t(K)) - log p_X,t-(Phi_u,t(K))
    pi_K,t+(x) = initial_logK_density(x) * exp(sum_r ell_r(exp(x))) / Z_t

`Phi_u` は既存deflecompのばね・重力平衡とFK。異なる親chart間では共通測度への体積係数を含める。これも指定された高集中局所Gaussian代理の計算であり、厳密な大域SO(3)密度への置換とは主張しない。

主K記憶は、既存の明示的初期log K Gaussianと各新観測の密度比因子の積である。局所Laplaceの不成立を理由に因子を捨てない。全体の正規化定数Zと全体モーメントは未計算として明示する。有限のZを持つ条件と上下界、chartの近似位置、密度照会不能点を記録し、評価不能を零尤度へ置換しない。

制御用Kの数値代表は、全履歴因子を保持した同じ連続密度から選ぶ。初期事前のモード・Cholesky列の正負方向・全列を合わせた連成方向と、前回の評価済み代表を決定論的な起点とする。完全な累積密度と現指令での安定平衡を評価して起点を選ぶ。初回、または固定起点が前回代表より優れるときだけ、密度scoreによる更新を既定で一回行う。Armijo条件を満たす評価済み点だけを採用し、採用点の密度・score・評価回数・探索開始理由と終了理由を記録する。前回代表が引き続き最良なら、同じ代表点における新因子の密度とscoreを正確に再評価し、新たな非線形試行点を作らず保持する。新しい密度比因子がない周期は代表・密度・scoreを厳密に保持し、現指令での平衡だけ再計算する。これらの起点は数値最適化に使い、モンテカルロ、K分布やその積分の代用、大域MAPとは扱わない。初期K分布と全履歴因子自体は変更しない。

旧実走では、単一座標ずつの起点選択からK3が約22.36に留まり、補助平衡の関節3が上限2.7925 radへ張り付いていた。その結果、関節3の指令感度と目的関数勾配が0になっていた。連成起点を加えた初回の短期計測では、この拘束を解消した。20周期ずつの計測は代表選択と計算時間の確認であり、通し実行や物理到達成功の証拠とは区別する。得たKによる平衡たわみ補償方向を初期指令候補にし、同じKを一周期の指令作用補正にも使う。

制御側は同じdensity ID・身体source ID・時刻・指令を照合する。`StiffnessCommandMap` が、現在の身体事後に平衡角差を右作用する一周期の指令依存分布族を定める。現在指令では厳密な恒等操作であり、KモデルのFKへ再中心化しない。前処理の感度もKKT式から `dtheta/dq=H^{-1}diag(K)` とする。補正された完全な規準に対して、速度・加速度・関節限界内で同じ勾配更新を一回行う。選定に使った補正を次周期の事前にも同じsource IDのまま適用する。無観測では観測更新が身体・剛性とも厳密な恒等操作となる。まだ新観測のK因子がない場合は、未取得のKによる補正を実施したとは記録しない。

## 指令の規準と表示

同じ共同候補から `marker^-1 * hand` の相対分布を伝播し、既知のマーカー→目標関係における密度を規準とする。比較段階だけ位置Gaussianと方位Binghamの積へ近似する。位置log determinant、方位log normalizer、全成分log-sum-expを含める。相対照会までは全交差ブロックを保持する。

観測由来の目標mixtureは、内部状態の単峰化と区別する。有効なマーカー観測の時点で、各観測枝のマーカー条件付き代理を共通の更新済み身体周辺へ作用させ、既知のマーカー→スイッチ関係で根元座標系へ伝播して記録する。全成分・weight・log weight・画像観測時刻・指令・版をIKと表示の同じ入力へ渡す。画像欠落中は、根元目標周辺の姿勢・共分散・混合重みを固定する。身体の現在事後へ条件付け直して目標を動かさない。身体との交差共分散は明示した更新・輸送を行い、相対照会まで保持する。内部状態の未知マーカー周辺と、記録した固定目標mixtureを同一とは説明しない。

画像欠落中の身体観測には、環境gainを0としたcut／Schmidt近似を使う。身体の予測・生の事後共分散をP0・P、予測身体-目標交差をCとし、交差を支持上で `P P0^+ C` へ更新する。身体再表現の同じ座標輸送を適用し、根元マーカーの平均・周辺共分散は記憶値を保持する。これを完全な環境Bayes事後とは呼ばない。成立条件と監査項目は [逐次更新の固定地図規定](REQUIREMENTS_SEQUENTIAL_UPDATE.md#画像欠落中の固定地図と身体更新) に記録する。

通常の接近では毎周期、完全な負の対数規準の勾配から一回の短い更新とline searchを行う。マーカー喪失時は、同じK補正された指令作用を使う減速・静止・局所探索へ移る。平均・モードの感度だけの代用や少数点による分布積分を行わない。勾配の有限差分は指令に対する数値微分で、身体候補のサンプリングではない。

関節限界に近づく場合は、次の速度で移動する距離と、その後の停止距離を残せる範囲へ指令を制限する。現在位置から限界までの距離D、加速度上限a、次周期幅dt、限界方向の次速度wについて `dt*w + w*w/(2*a) <= D` を満たす。位置・速度・加速度制約を維持したまま、限界到達前から減速する。

既存の一次Bingham再表現 `A=-2 N Omega^-1 N^T` は、浮動小数点の行列積で生じる反対称成分だけを除去する。`r^T A r` は反対称成分によらないため、分布や共分散、近似次数は変わらない。固有値のfloorや分散縮小による対処は行わない。

不透明ロボットは物理側の重力たわみ姿勢、半透明モデルは現在指令の剛体FK。RGB点は、同じ推定共同状態の根元→各リンク原点・軸端点へのGaussian照会である。局所変換周辺を配置したものや、物理姿勢へ再中心化したものではない。

描画点もGaussian分位点への決定論的照会で生成する。推定・伝播・融合・剛性記憶・描画にMonte Carloを使わない。乱数は物理側の模擬観測生成だけにある。点径・点数・軸長・画像サイズ・RViz設定を保持する。

実際のsnapshot・MarkerArray・画像・剛性密度と提案・source ID・版・時刻・指令を照合する。失敗時は失敗tickと最後に公開したtickを分けて停止理由を表示し、旧表示のまま動作中を装わない。
