## 1. 実装するもの

`hiroya1224/ProbTF-demo` の `ros/examples/` に、新規パッケージ `probtf_observation_fusion_demo` を実装する。

直接与えられた各リンクの座標変換候補分布を伝播し、各センサが個別に推定した分布を後段で融合する。その結果から、途中リンクを含む身体の推定実姿勢の分布を更新し、同じ分布をRVizで表示するデモである。

**中心に据えるのは、座標変換候補の分布と、その全共分散による伝播・更新である。剛性パラメータから平衡姿勢を生成して、それだけを候補にする構成にはしない。**

次の条件をすべて満たすこと。

1. 4例を同じディレクトリに置き、同一の推定・伝播・融合・表示実装を使用する。入口で変更するのは追加する観測データだけとする。
2. ProbTF coreを主計算に必ず使用する。coreをimportするだけ、デモ側の独自計算をcoreオブジェクトで包むだけでは不可。
3. dthesis第4章のBingham回転によるベクトル作用の高集中Gaussian代理を、後述する一次の規約で使用する。
4. 全共分散の二項を実際に計算する。観測後のリンク間・回転並進間・共通変換に由来する交差共分散を保持する。
5. センサごとの推定分布を作ってから、共通の演算で後段融合する。センサ数や組合せごとの推定器を作らない。
6. RVizで動く4例を必ず提供する。スイッチ押下デモのRViz設定を参照する。
7. **要求されていない物理仮定、観測情報、独立性、確定値、事前分布を実装都合で補わない。フォールバックで要件をすり替えない。**

この文書は実装指示であり、現行coreに全機能が実装済みだという説明ではない。必要な一次伝播・相関保持・分布融合の不足部分は、既存の設計を調べた上で必要最小限に実装する。

## 2. 4例と共通の入口

4つの入口を、**0：無情報・1：IMUのみ・2：カメラのみ・3：IMU＋カメラ** とする。無情報は全例に共通する観測前の前提であり、それだけを単独起動して確認する入口も提供する。カメラ観測には、手先カメラによるマーカー観測を使用する。IMU＋カメラも正式なデモとして、専用の起動入口とRViz表示を必ず提供する。

| 例 | 追加する観測 | 示す内容 |
|---|---|---|
| 0：無情報 | 空の観測集合 | 共通の初期候補分布の前向き伝播と、観測情報を加えない恒等更新をRVizで確認する。 |
| 1：IMUのみ | 途中リンクに取り付けたIMUの観測 | IMUが拘束する姿勢・方向の情報を融合し、途中リンクと手先の推定分布へ反映する。 |
| 2：カメラのみ | 手先カメラによるマーカー観測 | 観測整合性を身体候補へ戻し、根元側を含むリンク分布とリンク間依存を更新する。 |
| 3：IMU＋カメラ | 上記のIMU観測とマーカー観測の両方 | 同じ事前から各センサが個別に推定した分布を後段で融合し、その結果を各リンクの分布へ反映する。 |

4例で、身体形状、送信指令、初期の変換候補分布、物理側の場面、近似次数、推定器、RVizの表示規約を共通にする。例ごとに事前を変えて比較結果を作ることは禁止する。

IMU＋カメラのデモも、**同じ観測リストにIMUとマーカーの両方を渡すだけ**で実行する。併用専用の推定器・融合処理・表示処理は作らない。併用時にも、IMU単独の推定分布、カメラ単独の推定分布、後段融合結果を区別して確認できるようにする。

無情報の入口は、同じ共通実装へ空の観測リストを渡すだけとする。「無情報」は新しいセンサ観測情報を加えない意味であり、初期候補分布を一様分布・確定値・別の事前に変更する意味ではない。初期分布、前向き伝播、表示の計算経路は他の入口と共通とし、観測更新は恒等操作として扱う。

## 3. 状態は座標変換候補そのものの分布

時刻と送信指令を固定した一回の更新を基本単位にする。身体状態を

\[
X_t=(T_{1,t},\ldots,T_{n,t},E_t),\qquad X_t\sim P_t^-(\cdot\mid u_t)
\]

とする。\(T_{j,t}\) は実世界で生じているリンク間座標変換の候補、\(E_t\) は、必要な場合にマーカー配置やセンサ取付けなどの共有変量を含める場所である。入力として既知と与えられた幾何だけは定数として扱う。

方位には、直接与えられたBingham分布 \(B(r_j;A_j)\) を使う。並進にも直接与えられた分布を使う。両者の結合やリンク間の依存を、扱いやすさのために消さない。

**公称変換を置き、そこへ局所誤差を掛ける定義は禁止する。** 同様に、先に正しい姿勢を置き、そこにzero-meanノイズを足す説明・実装にしない。分布自身から計算するモードや数値計算用の局所座標は使えるが、それを外部から与えた「真の公称姿勢」と取り違えない。

根元からリンク \(k\) までの写像は

\[
g_k(X)=T_1\cdots T_k
\]

であり、推定したい絶対姿勢の分布は \((g_k)_\#P_t\) である。手先だけに分布を持たせ、中間リンクを確定姿勢として残す構成は不可。

### 入力データと情報の境界

- \(u_t\) は送信した制御値である。実現した関節角・リンク姿勢と同一視しない。
- たわみを関節角度の補正だけで表現できるとは仮定しない。各リンクの回転候補を、公称関節の1軸回転だけに制限しない。
- 初期の積事前を使う場合は、これまで議論した独立な初期リンク分布としてデータに明示する。更新後も独立だとは仮定しない。
- 既知の固定長や取付け、未知のマーカー配置、未較正の分布パラメータを区別し、値と出所を設定・READMEに記録する。
- 場面の数値はデモ入力として明示する。数値が設定ファイルにあるだけで、推定器にとって既知の物理量になったとは扱わない。
- センサ観測がないときに、たわみがゼロだと推定したことにしない。与えた事前を維持する。共通の更新前状態を表すために、観測後に動かせなくなるDirac事前を作らない。
- IMUより手先側の相対変換を、自動的に剛体・確定値へ変更しない。初期独立なら、その相対分布はIMU単独では変わらず、絶対姿勢には上流の更新が伝わる。この区別を表示する。
- カメラ観測だけで全リンクの全自由度が一意に決まるとは主張しない。残る不定性と相関も推定結果である。
- 物理シミュレータを使う場合、真の剛性、真のリンク姿勢、マーカーの真の根元姿勢、正解角点を、観測・明示的な既知入力以外の経路で推定器へ渡さない。
- `deflecomp` の力学計算を物理側の再現に使っても、推定候補をその剛性モデルの平衡姿勢の集合へ制限しない。

剛性は、身体分布から後で説明・記憶する側に置くという議論を維持する。今回の4例を完成させるために、新しい剛性逆モデル、剛性推定器、IK、接触処理を追加しない。更新した同時分布は下流から利用できる結果として残し、未知の \(u\) への対応を勝手な力学モデルで補わない。

## 4. 採用する高集中一次近似

### 4.1 ベクトル作用の代理

\(r\sim B(A)\)、\(v\ne0\)、\(r_v=\|v\|\) とする。第4章の式から、方向の代理モード \(x_\star(v;A)\) と接精度 \(\Lambda_{\mathrm{tan}}(v;A)\) を計算する。

このデモでは、高集中の主要係数による接共分散

\[
\Sigma(v;A)=\Lambda_{\mathrm{tan}}(v;A)^\dagger
\]

を使用する。\(\dagger\) は接平面上の逆であり、法線に分散を追加する操作ではない。

採用する一次代理を、明示的に次へ固定する。

\[
\boxed{
\mathcal M_1(v;A)=
r_v\left(1-\frac{\operatorname{tr}\Sigma(v;A)}{2}\right)x_\star(v;A)
}
\]

\[
\boxed{\mathcal V_1(v;A)=r_v^2\Sigma(v;A)}
\]

\(v=0\) は平均・共分散ともに0とする。

「一次」は、引用された代理式の分散 \(\Sigma\) の一次までを残す意味である。**平均の \(1-\operatorname{tr}\Sigma/2\) を落としてモード位置だけにしない。** 共分散の \(\Sigma^2\)、法線方向の二次分散、平均の二次補正は入れない。

現行 `induced_vector_moments_tangent` は、共分散の二次項と、既定で \(\Lambda_{\mathrm{tan}}+P_{x_\star}/3\) の有限補正を含む。そのまま呼んで一次実装と報告しない。この有限補正は共分散の主要係数より高次に効くため、今回の一次モードでは用いず、coreに採用次数を明示する。既存利用者の既定動作は一括で変更しない。

### 4.2 同じ回転から生じる交差共分散

Bingham行列 \(A\) の単純な最大固有値を \(\lambda_\star\)、その単位四元数を \(q_\star\) とする。\(R_\star=R(q_\star)\) とし、coreのHamilton積・`wxyz`規約で

\[
N=\Omega_L(q_\star)
\begin{pmatrix}0_{1\times3}\\I_3\end{pmatrix},\qquad
G_A=\lambda_\star I_3-N^\top A N,
\qquad C_A=2G_A^{-1}
\]

を計算する。これはBingham分布自身から導く高集中の共通回転共分散である。

\[
L_v=-R_\star[v]_\times
\]

とすると、採用次数で

\[
\operatorname{Cov}(Rv)=L_vC_A L_v^\top,
\qquad
\operatorname{Cov}(Rv,Rw)=L_vC_A L_w^\top
\]

となる。第4章の方向共分散とこの主要係数の対応は、dthesis付録の `appendix:eq:bingham-direction-precision-compatibility` を参照する。

方向ごとのGaussianを独立に置かない。周辺共分散の分極だけから交差共分散を作らない。全リンクを合わせた同時共分散 \(P\) の非対角ブロックを、次の伝播まで保持する。

これは、Bingham起点の高集中近似から導いた一次の共通計算である。最初からSO(3)/SE(3)上のGaussianを仮定した既存の別演算へ置き換えた、と解釈・実装してはならない。

### 4.3 次数と適用範囲を統一する

- 共分散と交差共分散は、身体の同時分布の広がりに関する**全体の一次**へ揃える。
- 各リンクの一次式を再帰的に代入すると一部残る \(O(P_1P_2)\) の分散積を、一方の経路だけ保持しない。
- 共通の回転、入力点、並進、センサ取付けの依存を保持する。同時分布を持たないまま周辺だけを継ぎ合わせない。
- 単一姿勢へ集中している成分に適用する。高集中にするための架空の情報、共分散縮小、最大モードの先決めを行わない。
- 観測が複数の姿勢候補を返した場合、その成分・重み・共有仮説の対応を保つ。全体を無条件に単一Gaussianへ潰さない。

方向別の \(\mathcal M_1(v;A)\) は、一般には全方向に共通する厳密な \(\mathbb E[R]v\) ではない。軸端点の代理平均を回転行列の列として再構成しない。本デモで使用するのは、指定された出力群に対するGaussian代理であり、厳密な大域同時分布を解析的に得たとは説明しない。

## 5. 全共分散を主計算にする

### 5.1 相関がある場合の実際の計算

分布自身の局所座標を \(z=(z_1,z_2)\)、平均を \((\mu_1,\mu_2)\)、同時共分散を

\[
P=\begin{pmatrix}P_{11}&P_{12}\\P_{21}&P_{22}\end{pmatrix}
\]

とする。出力の解析的な作用微分を \(J_1,J_2\) とし、Gaussian代理平均 \(m_Y\) は指定のcore伝播から求める。

支持上で

\[
B=P_{21}P_{11}^{-1},\qquad
P_{2\mid1}=P_{22}-BP_{11}B^\top
\]

を計算する。その上で、次の二項を**計算本体として**実装する。

\[
\boxed{S_{\mathrm{within}}=J_2P_{2\mid1}J_2^\top}
\]

\[
\boxed{
S_{\mathrm{between}}=(J_1+J_2B)P_{11}(J_1+J_2B)^\top
}
\]

\[
\boxed{S_Y=S_{\mathrm{within}}+S_{\mathrm{between}}}
\]

それぞれ \(\mathbb E[\operatorname{Cov}(Y\mid z_1)]\) と \(\operatorname{Cov}(\mathbb E[Y\mid z_1])\) である。条件付き期待値を記号のまま未評価にして残さない。

展開した次式を検算に使う。

\[
S_Y=J_1P_{11}J_1^\top+J_2P_{22}J_2^\top
+J_1P_{12}J_2^\top+J_2P_{21}J_1^\top.
\]

主計算で二項を保持し、それらの和と、同じ入力から直接作った \(JPJ^\top\) の一致を検証する。「全共分散を使用」とコメントするだけで、交差項を削除した分散加算を実装することは禁止する。

経路の合成、逆向き照会、固定軸端点への作用も、この共通演算と対応する解析的感度で処理する。カメラ相対から根元側へ戻す操作だけを別の確定変換計算にしない。

### 5.2 独立2リンクによる受入基準

既出の

\[
Y=R_0R_1(a+R_2b)
\]

を使用する。\(R_0,a,b\) は、この検算例で入力として与えた固定幾何である。\(R_{j,\star}\) は各Bingham分布自身のモードとする。

平均も総次数を明確にする。\(\delta\mathcal M_j(v)=\mathcal M_1(v;A_j)-R_{j,\star}v\)、\(v_\star=a+R_{2,\star}b\) として、

\[
\boxed{
\widehat m_Y=R_0\left[
R_{1,\star}v_\star+\delta\mathcal M_1(v_\star)
+R_{1,\star}\delta\mathcal M_2(b)
\right]
}
\]

とする。これは既出の \(R_0\mathcal M_1(a+\mathcal M_1(b;A_2);A_1)\) を全体の分散一次まで残したものである。coreでは平均の0次値と一次補正を区別して伝播し、補正どうしの積を入れない。

共分散の全体一次は

\[
\boxed{
S_Y=R_0\left[
\mathcal V_1(a+R_{2,\star}b;A_1)
+R_{1,\star}\mathcal V_1(b;A_2)R_{1,\star}^\top
\right]R_0^\top
}
\]

で照合する。前者の項は条件付き平均の共分散、後者は条件付き共分散の平均である。同じ \(R_1\) が両リンクの位置に作用する寄与を、\(a+R_{2,\star}b\) の中に残す。

さらに非ゼロの \(P_{12}\) を与え、5.1の条件付き計算が交差項を含めて一致するケースを検証する。独立時の式を、融合後へ無条件に再利用してはいけない。

### 5.3 相関による平均の一次寄与も残す

更新後のリンク間相関は、共分散だけでなく平均にも分散の一次で寄与する。\(P_{12}\ne0\) なのに、5.2の独立時の平均を無変更で使用しない。

2リンクでは、右回転座標の交差共分散を \(P_{12}\)、3次元標準基底を \(e_a\) として、独立時の一次代理平均に

\[
\boxed{
\Delta m_{12}=R_0R_{1,\star}
\sum_{a,b=1}^{3}(P_{12})_{ab}
[e_a]_\times R_{2,\star}[e_b]_\times b
}
\]

を加える。有限個の行列積で計算できる。例えば \(R_0=R_{1,\star}=R_{2,\star}=I\)、\(b=e_x\)、\(P_{12}=c e_z e_z^\top\) なら、この寄与は \(-c e_x\) となる。

一般の幾何写像 \(g\) では、各Bingham回転・各Gaussian並進を局所変数ブロック \(z_a\) とし、指定された独立時の一次代理平均に

\[
\Delta m_g=
\sum_{a<b}\sum_{\alpha,\beta}(P_{ab})_{\alpha\beta}
\left.
\frac{\partial^2 g}{\partial z_{a,\alpha}\,\partial z_{b,\beta}}
\right|_{z=\mu}
\]

を加える。混合微分は、coreの座標変換の積・逆・点作用の具体式から評価する。回転並進の交差ブロックと、共有する変量も同様に含める。独立時の項を取り出すのは計算上の整理であり、実際の身体状態を独立分布へ置換する操作ではない。

幾何写像の2階微分が現れるが、使う統計量は共分散だけであり、これは \(P\) の一次の項である。\(P^2\) の項や4次のGaussianモーメントを追加する話ではない。この相関補正は、既出の一次同時近似を計算可能にするための明示的な計算則であり、原稿の方向別代理式にそのまま掲載済みだとは説明しない。

同じ確率変量が経路に複数回現れる場合も、出現ごとに新しい独立ブロックを作らない。元の同じ変量の作用として微分・合成する。

### 5.4 センサ・描画照会の共通の代理

身体の局所同時分布を \(\mathcal N(\mu,P)\) とする。センサまたは点照会 \(s\) の平均 \(m_s^-\) は同じcoreの一次伝播から得る。解析的感度を \(H_s\) とし、

\[
C_s=PH_s^\top,\qquad S_s^-=H_sPH_s^\top,
\qquad c_s=m_s^--H_s\mu
\]

と置く。\(S_s^-\) は5.1の全共分散の二項から計算し、上式と一致することを検証する。

\[
\begin{pmatrix}z\\z_s\end{pmatrix}
\sim\mathcal N\left(
\begin{pmatrix}\mu\\m_s^-\end{pmatrix},
\begin{pmatrix}P&C_s\\C_s^\top&S_s^-\end{pmatrix}
\right)
\]

という局所同時Gaussian代理を使う。対応する写像は \(z_s=c_s+H_sz\) である。切片を用いて、代理平均をモード位置へ勝手に変更しない。

出力間の交差共分散も \(H_sPH_r^\top\) とする。共通の \(P\)・近似次数・状態版から作ること。身体への持ち上げ用の \(S_s^-\) だけ別の式へ差し替えない。

## 6. 各センサで推定し、後段で分布を融合する

### 6.1 センサ局所推定の契約

センサの対象写像を \(Z_s=h_s(X)\) とする。例えば、IMU取付リンクの方位、または

\[
T_{CM}=(T_1\cdots T_nT_{nC})^{-1}T_{BM}
\]

というカメラ相対マーカー変換である。\(T_{BM}\) や \(T_{nC}\) が不定なら、その候補も同じ身体・環境の分布に含める。

共通事前から \(Q_s^-=(h_s)_\#P^-\) の代理を計算する。各センサは、自分の観測だけで \(Q_s^+\) を推定する。センサ局所推定の出力には最低限、次を含める。

- 対象の座標系・写像・成分の対応。
- 更新前 \(Q_s^-\) と更新後 \(Q_s^+\)、または既知の参照事前を含む同等の分布表現。
- 共通事前の版、観測時刻、送信指令、センサと観測の識別子。
- 分布の支持、近似次数、混合成分と重みがある場合はその情報。

**身体の融合器が受け取るのは、この推定済み分布である。生のIMU値と画像の尤度を一つの専用推定器へ集める構成は不可。**

既存センサ実装の出力が尤度なのか、ある事前を既に含む事後分布なのかをソースで確認する。不明な事前を一様だと決めつけない。異なる既知事前 \(\rho_s\) を使った出力なら、その参照事前を分布比で除く。重複する事前や同じ画像・観測を二重に加えない。

一回の融合では、更新前分布から定めた同じ局所座標・支持基底へ、各センサの事後分布を座標変換してから分布比を取る。特に方向の \(S^2\) 分布では、更新前と更新後それぞれのモードに接する別々の3次元退化Gaussianを、そのまま割らない。融合には凍結した同じ2次元の内在局所座標を使う。3次元の点作用Gaussianは作用・描画の代理であり、別の支持を持つ融合密度へ無条件に昇格させない。

### 6.2 単独センサの分布を身体へ戻す

共通事前を使う場合の原則は

\[
P_s(dX)=\int P^-(dX\mid Z_s=z_s)Q_s^+(dz_s)
\]

であり、密度では

\[
p_s(X)=p^-(X)\frac{q_s^+(h_s(X))}{q_s^-(h_s(X))}
\]

となる。比は共通の支持上で扱う。

5.4の凍結したGaussian代理では、未評価の積分を残さず次を計算する。

\[
K_s=C_s(S_s^-)^{-1},\qquad
\mu_s=\mu+K_s(m_s^+-m_s^-)
\]

\[
\boxed{
P_s=
\underbrace{P-K_sS_s^-K_s^\top}_{\mathbb E[\operatorname{Cov}(z\mid z_s)]}
+\underbrace{K_sS_s^+K_s^\top}_{\operatorname{Cov}(\mathbb E[z\mid z_s])}
}
\]

ここでも全共分散の二項を両方残す。センサの取り付いたリンクだけを書き換える実装にしない。

### 6.3 同じ演算で後段融合する

同じ更新前分布を基準にして、各センサの単独事後分布を合成する。

\[
\boxed{
p^+(X)\propto\frac{\prod_{s=1}^{m}p_s(X)}{p^-(X)^{m-1}}
}
\]

または二項演算

\[
p_a\odot_{p^-}p_b
=\operatorname{Normalize}\left(\frac{p_ap_b}{p^-}\right)
\]

を用いる。\(P^-\) が単位元となるため、観測が0件でも同じ処理が成り立つ。

各センサの新しい観測が、共有状態 \(X\) を条件に独立である範囲の式である。共有する較正値や配置を別々の独立量に複製して、条件を見かけ上成立させない。同じ観測を再送しただけなら新情報として再融合しない。

Gaussian代理の同じ支持・座標では、情報差を

\[
\Delta\Lambda_s=(S_s^+)^{-1}-(S_s^-)^{-1},\qquad
\Delta\eta_s=(S_s^+)^{-1}m_s^+-(S_s^-)^{-1}m_s^-
\]

として、次を計算できる。

\[
\boxed{\Lambda^+=P^{-1}+\sum_sH_s^\top\Delta\Lambda_sH_s}
\]

\[
\boxed{
\eta^+=P^{-1}\mu+
\sum_sH_s^\top(\Delta\eta_s-\Delta\Lambda_sc_s)
}
\]

\[
P^+=(\Lambda^+)^{-1},\qquad\mu^+=P^+\eta^+.
\]

6.2の単独事後分布からの合成と同値であることを検証する。センサ別の結果と全共分散の内訳は保持し、数値処理ではこの情報差の加算を使ってよい。

一回の融合では、全センサで同じ事前・局所座標・伝播結果を凍結する。IMUを適用した後でカメラの参照事前だけ取り替え、同じ後段融合だと説明することは禁止する。

混合分布が入力されるときは、既存の成分表現・出自を保った有限の分布演算として扱う。上の単一Gaussianの式を、混合全体を平均化する理由にしない。共通事前に元々ある成分ラベルを保持し、そのラベルで条件付けた共通事前に対して局所推定・持ち上げを行う。対応する成分の有限の組合せごとに積を計算し、その正規化定数を含めて重みを更新する。**任意の周辺Gaussian混合どうしの比が、有限Gaussian混合として閉じるとは仮定しない。** 対応を失った分布を勝手に同じ成分とみなさない。成分を保持できていない場合は、その観測の融合が完成したと報告してはならない。

成分の重みも具体的に計算する。共通事前を \(p^-(z,h)=\pi_h\mathcal N_h(z)\)、センサ単独の身体事後を \(p_s(z,h,k_s)=\alpha_{s,h,k_s}\mathcal N_{s,h,k_s}(z)\) とする。\(h\) は元の共通事前の成分ラベルである。組 \((h,k_1,\ldots,k_m)\) の重みは

\[
\widetilde w=
\pi_h^{1-m}\left(\prod_s\alpha_{s,h,k_s}\right)C
\]

で計算する。ここで、その組の事前Gaussianを \(\mathcal N(\mu_0,P_0)\)、各単独事後を \(\mathcal N(\mu_s,P_s)\) と略記し、同じ支持上で

\[
\Lambda_*=\sum_sP_s^{-1}-(m-1)P_0^{-1},\qquad
\eta_*=\sum_sP_s^{-1}\mu_s-(m-1)P_0^{-1}\mu_0,
\qquad P_*=\Lambda_*^{-1}
\]

\[
\gamma=\sum_s\mu_s^\top P_s^{-1}\mu_s
-(m-1)\mu_0^\top P_0^{-1}\mu_0
\]

\[
\boxed{
\log C=\frac12\left[
(m-1)\log\det P_0-\sum_s\log\det P_s
+\log\det P_*-\gamma+\eta_*^\top P_*\eta_*
\right]
}
\]

と評価する。融合後のその成分は \(\mathcal N(P_*\eta_*,P_*)\) である。全組の重みをlog-sum-expで正規化する。成分ごとに条件付きGaussianだけを正規化し、成分間の観測整合性を捨てない。これらも有限個の行列演算であり、未評価の積分やサンプリングを残さない。

### 6.4 IMUとマーカーで与えてはいけない情報

- 重力方向だけのIMU観測を完全な3自由度方位観測にしない。磁気方位、確定yaw、架空のyaw分散を追加しない。
- IMU自身の情報増分が未観測方向を直接拘束しないことを検証する。身体事前や他センサとの相関を通じて、その方向が更新されることとは区別する。
- 方向の \(S^2\) 分布が集中することと、方位全体の \(SO(3)\) 分布が単一姿勢に集中することを混同しない。
- マーカーのカメラ相対観測から、根元基準の既知マーカー姿勢を生成しない。必要な根元との関係は、実際に与えた既知幾何または不定な候補を使う。
- マーカー検出が複数候補を返す場合、真値に近い解を選んでから融合しない。観測された成分と重みを残す。
- 未検出は有効な姿勢観測ではない。別のセンサや真値から観測を補完しない。

## 7. 更新状態の保持とBinghamへの再表現

後段融合で得た \((\mu^+,P^+)\) は、リンク別の周辺だけでなく、**同時状態として保存する**。すべての中間リンク・手先・センサの次回照会は、この同じ状態版を参照する。

Binghamパラメータへの再表現も、採用した高集中一次の対応に揃える。更新後の各リンク方位の局所モードを \(q_j\)、右回転ベクトル座標の周辺共分散を \(\Omega_j\) とし、4.2と同じ規約の接基底を \(N_j\) とすると、

\[
\boxed{A_j^+=-2N_j\Omega_j^{-1}N_j^\top}
\]

が最大固有値0の規約における一次の再表現となる。これは4.2の \(C_A=2G_A^{-1}\) を逆に解いたものである。四元数の接座標の共分散 \(S_{q,j}\) を使う場合は \(\Omega_j=4S_{q,j}\) なので、係数を混同しない。

この式は、同じ単一姿勢集中の正定値な回転共分散に対して使う。\(\Omega_j\) は更新後の局所座標へ移した後の回転周辺共分散とする。混合分布は成分ごとに再表現し、複数成分を一つの平均・共分散へまとめて代入しない。入力として確定した回転は既存の確定分布表現のままとし、連続した未観測方位を持つ縮退Binghamを、この式のために可逆化しない。

これは採用した高集中近似内の再表現であり、厳密なBinghamモーメント整合方程式を解いた結果とは呼ばない。厳密な式と近似を区別する。

新しい局所座標へ移す場合には、その座標変換のJacobian \(G_j\) により、交差ブロックも

\[
P_{jk}\leftarrow G_jP_{jk}G_k^\top
\]

と移す。回転並進の結合も同様である。各 \(A_j^+\) を保存した後に積分布を作り直して、\(P_{jk}\) を消してはいけない。

現在の `GaussianLatentStore.put_factor` / `replace_factor` には、個別factorの置換時に関連交差ブロックを削除する処理がある。これを無検証で更新経路に使わない。必要な同時更新は、因子・結合・交差共分散・版を整合させて一括で公開する。

再表現・局所座標の更新後には、必要な作用感度も同じ分布から更新する。単独センサの周辺一致や融合の代数的同値のテストは、同じ凍結代理に対して行い、再近似を挟んだ値まで厳密一致すると主張しない。

## 8. 数値計算と失敗の扱い

**伝播・持ち上げ・融合の主経路に、モンテカルロ、粒子伝播、sigma-pointによる代行を入れない。** 既存のBingham四元数2次・4次モーメントの求積経路へ切り替えて、今回の高集中代理を実装したと説明することも不可。

一次の方向Gaussianは法線方向の分散が0になり得る。固定幾何や観測の不定性により、他の共分散も特異になり得る。このため、**支持部分空間で計算することを最初から主アルゴリズムに含める**。

- 固定成分は確率的な自由座標から分離する。
- 逆行列の式は支持上の線形方程式として実装する。必要な接平面・自由部分空間を明示する。
- 事後分布と分布比も、対応する同じ支持上で計算する。
- 法線零固有値へのjitter、固有値のfloor、架空の独立分散を加えない。
- 有意な負固有値、不整合な支持、集中条件外の分布を、クリッピングや自動縮小で有効化しない。
- 丸め誤差の許容値と数学的な分散の設定を区別し、誤差許容による処理は記録する。

無観測・未検出で新しい情報がないことと、要求された演算が未実装・数値不正であることを区別する。前者は恒等更新である。後者を「前回値を採用して成功」として隠さない。計算できない対象・原因を診断として出す。

今回の有効な4例に必要な演算を未実装のまま残し、診断が出るので完成とすることも禁止する。要件を満たす演算を実装して4例を動かす。要求どおりに実装できない事項が残った場合は、未達箇所と理由を明確に報告する。

## 9. coreとデモの責務

### coreに置く計算

- 指定次数のBingham→ベクトルGaussian代理。
- Bingham由来の共通局所共分散と、共有する方向・リンク間の交差共分散。
- 5章の条件付き計算による全共分散と、経路・軸端点のモーメント照会。
- 6章の分布の持ち上げと、参照事前を補正する共通の後段融合。
- 支持部分空間の計算、同時状態の整合した更新、一次のBingham再表現。

既存のBingham・幾何・依存管理・provenance・分布メッセージの部品を優先して使う。既存APIで不足する場合は、上記の計算に必要な拡張をcoreに加える。

`DependencyAwareMomentEvaluator` や `GaussianLatentStore` は、共有状態の保持や行列演算の再利用候補である。しかし、それらを呼ぶだけで第4章の指定代理になったとはみなさない。Binghamからの導出、代理平均、全共分散、次数の一致を実装とテストで接続する。

### デモに置くもの

- 明示的な場面・指令・初期分布・観測データ。
- IMUとマーカーの入力アダプター、および既存センサ局所推定器への接続。
- 一回の共通更新と再実行の進行。
- coreの不変snapshotをROS/RVizへ渡す表示アダプター。

センサ固有の設定や旧スイッチ押下処理をcoreへ持ち込まない。逆に、coreにあるべき伝播式をデモの便利関数へ複製しない。

### SOLID・YAGNI・KISSの具体的な適用

- 入力、センサ局所推定、分布演算、状態管理、表示の責務を分ける。
- 融合器はセンサ型に依存せず、推定済み分布と参照事前の小さな契約に依存する。
- センサを追加しても、共通の融合・伝播ループを変更しない。
- 例ごとのクラス階層、汎用プラグイン基盤、新しい候補フレームワーク、有限Dirac事前、汎用密度積分エンジンを作らない。
- 意味のある小さな関数・データ型を使う。形式上の原則遵守のための抽象クラスやfactoryを増やさない。
- 力センサ、接触、目標ボタン、到達制御、独立したIKモジュールを追加しない。

## 10. RVizは必須。同じcore結果を表示する

### 10.1 参照する設定

次を実際に読んで、新デモの設定へ反映する。

`ros/examples/probtf_switch_press_demo/rviz/switch_press_demo.rviz`

参照時点では、点サイズは約0.01、軸長は約0.1、リンクの描画点数は180、マーカーは200、カメラ画像ドックを含むレイアウトが設定されている。これらはユーザー調整済みである。

元の `.rviz` は変更しない。新ディレクトリへコピーし、新デモに必要なトピック・フレーム・表示対象を対応させる。旧デモ固有の不要表示は新しいコピーで整理してよいが、ユーザー調整済みの点サイズ・画像ドックの寸法・視点・軸長などを都合で再設定しない。作業開始時の元ファイルを基準に、終了後にバイト単位で不変を確認する。

Fixed Frameには、実際の入力・推定状態で使用する根元座標系を設定する。旧設定の `world` に合わせるためだけに、未指定の確定 `world`→`base_link` 変換を作らない。

### 10.2 表示経路を一本に固定する

このデモでは、**coreが計算した各リンクの原点・XYZ軸端点のGaussian代理を、不変snapshotから読み取り、ROSの `MarkerArray` で描画する経路**を主経路とする。RViz側で変換列を再伝播しない。これは今回指定する表示実装であり、計算失敗時に切り替える代替経路ではない。

軸端点は、同じ身体の同時分布と同じ経路への点作用照会として求める。表示用の位置・方位の独立な積分布を作らない。各軸の代表点とGaussianの広がりは、coreの平均・共分散をそのまま使用する。

点群表示は `MarkerArray` の `SPHERE_LIST` を使い、**解析的に計算済みの出力Gaussianから描画点だけを生成する**。描画乱数や標本数は推定・伝播・融合の計算結果に一切影響させない。変換候補をサンプルして経路合成することとは区別する。

現行 `ros/core/probtf_rviz/src/probabilistic_tf_display.cpp` は、旧デモ固有のprovenance以外では変換分布をサンプリングして合成する経路を持つ。また、その点モーメント照会経路も現状は別のBinghamモーメント求積である。**新しいnativeメッセージを送れば自動的に今回の解析伝播が表示される、と想定しない。旧provenanceの偽装も禁止する。**

新しい `.rviz` では、今回の分布表示が上記の計算済みGaussianのトピックを読むよう設定する。別の経路で計算した分布を同じ推定結果として重ねない。

表示アダプターの入力snapshotには、各原点・軸端点の平均、共分散、照会ID、座標系、時刻、指令、共通状態版を保持する。`MarkerArray` 自体には共分散フィールドがないため、同一性は次の二段で検証する。

1. core snapshotから表示アダプターへ渡した平均・共分散と出自を直接照合する。
2. 同じsnapshotと固定された描画seedから再構成した点列を、実際にserialize/deserializeしたROSメッセージの点列、scale、色、frame、stamp、namespace/idと照合する。

描画点の経験共分散が近いだけでは、同一性を確認したことにしない。この確認のためだけに新しい分布メッセージ体系を作る必要はない。

### 10.3 RVizで確認できる内容

- 更新前と更新後の、途中リンクを含む各リンクの座標軸・軸端点分布。
- 手先の推定分布。
- 使用したIMUの対象リンク・観測方向、およびカメラ相対マーカーの推定分布。IMU＋カメラの例では両方を表示し、各センサの単独推定と後段融合結果を確認できるようにする。
- マーカー観測に用いた画像・検出結果。画像を生成する場合も、推定器へ渡すのは観測入力である。
- 有効な観測数、観測時刻、送信指令、状態版、現在が更新前・単独センサ推定・後段融合後のどの段階か。
- 全共分散の二項を確認できる数値診断。異なる分布を作って二項を別の「推定姿勢」として表示しない。

真の物理姿勢を比較表示する場合は、物理側の参照であると区別し、候補分布を真値に再中心化しない。剛体的な形状を参考表示しても、それを推定器の公称変換に転用しない。

各launchは既定でRVizを起動する。`rviz:=false` は検証・既存RVizへの接続に使用できる。初期分布と観測後の変化が見える進行、終了状態の保持、同じ入力での再実行を共通に提供する。無情報の入口では、同じ指令・時刻の更新単位で、観測を加えず分布が維持されることを確認する。

## 11. 必須の検証

テストは以下の具体的なリスクを検証するものに限定し、実装をそのまま写したテストや大量の形式的テストは作らない。

| 検証 | 合格条件 |
|---|---|
| 共通実装 | 4入口の差が追加観測データだけ。共通の事前・指令・演算器を使う。 |
| 一次代理 | 平均補正を保持し、共分散の二次項を含めない。Bingham由来の共通共分散と方向共分散の主要係数が一致する。 |
| 全共分散と平均 | 条件付きの二項とその和を検証し、非ゼロ交差共分散を含む直接計算と一致する。5.3の平均の相関寄与も検証する。 |
| 独立2リンク | 5.2の式と一致し、共通の第1回転の寄与を落としていない。 |
| 無観測・無情報 | `no_sensors.launch` が共通実装へ空の観測リストを渡す。0件、または \(Q_s^+=Q_s^-\) のセンサ追加では分布が変わらない。 |
| 単独センサ | 凍結した同じ代理で、持ち上げ後の対象周辺がセンサの \(Q_s^+\) と一致する。 |
| 後段融合 | IMU＋カメラデモが、単独例と同じ処理で動く。各センサの単独推定分布と融合結果を記録し、共通事前の補正、交換順序・括弧の変更、単位元が整合する。 |
| 依存保持 | 融合で生じたリンク間共分散が保存され、次の絶対姿勢・軸端点照会へ効く。周辺だけで再構成していない。 |
| 観測可能性 | IMUが未観測yawの情報を捏造しない。未知マーカー配置を既知にしない。識別不能性を成功値へ置換しない。 |
| 複数候補 | 観測が実際に返す成分・重みを保持し、真値による候補選別や暗黙の単峰化がない。 |
| 支持 | 接方向の階数不足を本来の支持上で処理する。法線jitterなしで計算できる。 |
| Bingham再表現 | モード・一次共分散の往復と四元数の半角係数が一致する。再表現で交差ブロックを落とさない。 |
| 非MC伝播 | 主計算で乱数生成・変換サンプルを禁止した状態でも、4例の伝播・持ち上げ・融合を実行できる。描画乱数を変えても結果が同じ。 |
| 情報境界 | 同じ観測入力のまま物理側の真値だけ変更しても、推定結果は勝手に変わらない。 |
| 表示の同一性 | 実際にROSへ送った値・時刻・指令・版を、推定に使用したcore snapshotと照合する。 |
| RViz実行 | 無情報・IMUのみ・カメラのみ・IMU＋カメラの4入口を実際に起動する。無情報では共通の事前とその伝播を保持して表示し、観測ありでは中間リンクの分布と更新前後の変化が見える。併用例ではセンサ別推定から後段融合への変化も確認する。設定ファイルがあるだけでは合格としない。 |
| 元の設定の保護 | 既存スイッチ押下デモの `.rviz` が作業前後でバイト一致する。 |

カメラ更新で全リンクの全分散が必ず減る、すべての平均が真値へ近づく、といった根拠のない合格条件は設けない。更新される方向・残る方向・依存を、入力の情報量と対応させて説明する。

数値計算の検証用には、固定された解析的な小例を使う。必要なら既存の決定論的モーメント評価を独立の検算に使えるが、本番の伝播方式へ切り替えない。モンテカルロとの一致だけを正しさの根拠にしない。
