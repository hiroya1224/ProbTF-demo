# 最小参照実装への変更（2026年10月19日・ユーザー指定）

共同方位版 `7cab05a` / tag `joint-rotation-stiffness-20261019` を保存した後、二つの候補測度と一つの指令選定器を基本構成にする。

1. 身体・環境の共同候補 $\mu_t(dB,dE)$ を一つ保持する。画像・IMUで通常のBayes更新を行い、リンク間と環境との全交差を保持する。局所取付並進は既知Dirac、リンク方位は既存のBingham由来の候補とする。身体BFSは外す。
2. 別の剛性候補 $\Upsilon_{K,t}(dK)$ を、全リンク局所方位の共同観測後／前密度比 $L_t(K)=p_{R,t}^{+}(Q(u_t,K))/p_{R,t}^{-}(Q(u_t,K))$ で更新する。全リンク回転crossを保持し、補助力学モデルは同じ取得時刻の実送信指令を使う。K-BFSとevidence計算、全履歴密度の反復再評価を外す。必要ならlog K上の単一Gaussianへ逐次近似してよい。これは全履歴密度保持からの明示的な簡略化である。
3. 試行指令cへの候補は $\mu_t^{(c)}=(A_{u_t\to c}^{K_{est}})_\#\mu_t$ とする。現在の観測済み身体へモデルが予測する指令変更分だけを作用させ、モデルの絶対姿勢で身体候補を置換しない。モデルにない実機のずれを消さない。
4. 唯一のタスク規準は $S_t(c)=\mathbb E_{\mu_t^{(c)}}[\|p_H(B)-p_G(E)\|^2]$。現在指令から短い有限ステップを一回選定して物理的に実行し、再観測する。完全な正規化密度J、Running Gradient Trackingの二階系、局所Hessian、Fisher行列、独立した速度状態を指令選定へ使わない。視野因子は外す。
5. 独立したfresh goalと旧IKの各種phaseを外す。目標は同じ共同候補の環境変数と既知のmarker→switch取付から照会する。画像を新しい独立なtask分布として再投入しない。
6. 物理シミュレータの慣性・ばね・減衰と、時刻付きの全観測・実送信指令・実区間K作用履歴は保持する。原取得時刻・指令・同時刻内sequenceを変えない。真値は通常推定・制御へ渡さない。モンテカルロとcore/RViz/画像・粒子・軸サイズの改変は禁止のまま。

主要状態は共同身体・環境候補、剛性候補、実送信指令。内部身体事後の単一Gaussian/Bingham近似は従来どおり可能だが、同じ共同lawを推定・選定・表示で使う。新しい画像のnative mixtureは観測尤度として全成分を扱い、先に一枝選択しない。

最初に検証する本質的問題は「全リンク方位の共同密度から選んだKが、手先位置の予測にも適切か」。方位適合と手先位置適合は同じではなく、成功・真のK復元・到達改善を未測定で主張しない。

過去のBFS・完全J・全履歴K・fresh goal・二階追従の維持規定は、この最小参照経路では本指定によって置き換える。履歴実装・タグは比較用に保存し、今回の既定と混同しない。
