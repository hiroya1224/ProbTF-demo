# 一回の完全IKと時間付き位置参照

2026年10月17日、ユーザーの振動指摘に従い、3回の仮想IKによる1.5秒のホライゾンを撤回した。本書が現行仕様であり、撤回した実装の仕様・実測は [SHORT_HORIZON_IK.md](SHORT_HORIZON_IK.md) に保存する。

各制御requestは、保持した身体・固定目標の全候補、全交差共分散とsource、同じ実行Kの補間sampleと安定平衡branchを捕捉する。その分布と作用を一回の計算中に固定し、完全な正規化Gaussian／Bingham-mixture規準Jの勾配を一回評価して、一つの次関節位置 `q_next` と所要時間 `dt=0.5 s` を選ぶ。全covariance、log determinant、Bingham正規化、全goal成分・weight・log weightと位置s条件を保持する。8回のbacktrackと許容集合内部への修復は同じJ／sの有限試行で検証し、規準を位置平均だけの損失へ置き換えない。

出発時刻を `t_source`、出発指令を `q_source` とし、各物理tickでは、

```text
a = clip((t - t_source) / dt, 0, 1)
q_ref(t) = q_source + a * (q_next - q_source)
requested_velocity = (q_ref(t) - q_actual) / actual_tick_dt
```

を参照する。ここで `q_actual` は実際に送信済みの現在関節指令であり、物理世界の真のたわみ関節角を指さない。所要時間は停止期限ではない。`t_source+dt` 以後はa=1、参照位置q_nextを保持し、次planまで残りの位置誤差を同じ式で追う。経過したという理由だけで零速度を要求しない。既存の速度・加速度・関節・停止距離制約を使い、補間を遅着採用時刻から数え直さない。

所要時間後も位置参照は有限q_nextであり、一定速度をその先へ外挿しない。旧3fc6方式の追加端点停止速度や、各軸の通過に応じたclampも使わない。物理servoでJ・IK・確率候補を再評価せず、仮想のq2・q3を計算しない。実際に目標へ追いついたときやマーカー喪失・既存の停止条件では、同じハードウェア相当の加速度制約を守る。位置参照への厳密一致や、非線形IKの連続性を保証する方式とは説明しない。

推定Kの連続密度・代表・元記録と、制御用の補間Kを分ける。coordinatorは計算待ちでも実dtに応じてK補間を続け、一回のIK中は開始時sampleを固定する。完成したplan・身体／目標law・実行K・snapshotを一体で採用する。実際に実行した全区間とその採用Kをledgerへ残し、遅着事後・次事前へ同じ作用を順に適用する。K補間から身体を再生成せず、全crossと固定根元目標を保持する。詳細は [EXECUTION_STIFFNESS.md](EXECUTION_STIFFNESS.md) に従う。

raw画像取得15 fps・物理動作20 Hzを目標とする非同期動作、raw検出中の停止待機と有効融合目標／IK採用後の復帰、既存の局所探索を維持する。推定・IK・表示の候補lawとsourceを一致させ、core・PDF・RViz設定を変更せず、モンテカルロを使わない。

テストと実配信検証では、完全Jの一回評価、次位置・source時刻と参照の式、所要時間後も有限目標を追うこと、共通bounds、凍結Kと実ledger、全候補の実wire／TF同一性を確認する。物理到達・衝突と、速度反転・指令差・加速度・手先変位を別に測る。旧3更新の571テスト、一時到達、過去sourceの到達を今回の振動解消や性能の証拠に読み替えない。

source `ef388266…` の最初の一回方式では、0.5秒の経過で零速度を要求する実装が残り、接近区間の約36%がその状態だった。実速度が零となったmarker70／IMU＋marker53区間は全てその経過後だった。この停止動作は撤回し、次のsourceで有限位置の追従を継続する。元の観測・推定・実行記録と実測は履歴として保存し、その結果を停止解消や振動解消の証拠にしない。
