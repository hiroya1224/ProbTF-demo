# 角速度伝播と地磁気の三条件比較

`compare_rolling_bag.py`は、実測された角速度を一標本ずつ伝播し、地磁気の使い方を変えた三条件をモーションキャプチャと比較する。ROS masterを起動せず、bagを読み取り専用で開く。

| 条件 | 現在時刻の出力 | 次時刻へ保持する状態 |
| --- | --- | --- |
| 角速度 | 角速度による予測分布 | 同じ予測分布 |
| 地磁気の融合あり（後処理のみ） | 角速度による予測と現在の地磁気因子の積 | 地磁気を加える前の予測分布 |
| 地磁気の融合あり（次時刻の初期値にも利用） | 予測と現在の地磁気因子の積 | 地磁気を加えた事後分布 |

方向候補を取り込む処理を「融合」と呼び、四元数積などによる座標変換の二項演算の「合成」と区別する。図・表・動画では上記の条件名を使う。

加速度による重力方向の更新は使わない。計算には`probtf_estimators.orientation_imu`の6点cubature、`probtf.bingham`の四元数積の二次モーメントとBinghamモーメント整合、地磁気の方向因子を使う。モーメント整合の初期値には前時刻の固有値を使い、二次モーメント残差を検査する。deprecatedのパッケージは読み込まない。

ProbTF-demoのルートで次を実行する。Python環境にはROS Noeticの`rosbag`、NumPy、SciPy、Matplotlib、numpy-quaternionを、動画生成には`ffmpeg`を用意する。ビジュアライザは同梱の`third_party/BinghamNLL`から読む。

```bash
/usr/bin/python3 ros/examples/probtf_orientation_demo/scripts/compare_rolling_bag.py \
  --bag ~/rosbags/20250310_delta_linear_rolling_1_2025-03-10-16-18-36.bag \
  --output ros/examples/probtf_orientation_demo/outputs/20250310_delta_linear_rolling
```

数値計算とグラフだけを作る場合は`--skip-video`を加える。保存済みの結果から評価・グラフ・動画を作り直す場合は同じ出力先と`--render-only`を指定する。この場合は推定状態を再計算せず、保存したモードと参照から誤差を集計し直す。短い区間の確認には`--duration 1.0`を使える。

入力は`/delta/imu`の`spinal/Imu`に含まれる`gyro_data`と`mag_data`、および`/delta/mocap/pose`である。各メッセージの計測時刻を使い、モーションキャプチャを四元数の球面線形補間で対応付ける。共通の記録範囲外へは外挿しない。角速度は右端標本を時刻間隔中の値として用い、すべての標本を伝播する。

冒頭の1.0秒で世界の磁場基準方向を決め、その後の最初の参照方位から三条件共通の事前分布を作る。モーションキャプチャはこの初期設定と評価にだけ使い、その後の時間再帰に入力しない。角速度のバイアスは差し引かない。全方向の磁気較正も追加しない。

| 設定 | 既定値 |
| --- | --- |
| 初期Bingham集中度 | 100.0 |
| 角速度標本の等方的な作業分散 | 0.0001 rad²/s² |
| 地磁気方向の集中度 | 20.0 |
| Bingham正規化定数の数値計算点数 | 120 |
| 動画の表示頻度 | 8 frames/s |
| 各分布の表示標本数 | 180 |

これらの尺度は三条件の比較に固定したものであり、参照誤差を最小化して選んだ値ではない。分布の被覆率を較正した値とも扱わない。

出力先に`summary.json`、`timeseries.npz`、`timeseries.csv`、RPY・四元数・各軸と三軸の合成誤差のPDF/SVG/PNG、`bingham_comparison.mp4`、動画中の5時刻のPNGを保存する。四元数の並びは`wxyz`で、符号は時刻方向に連続にそろえる。RPYの角度は参照時系列に最も近い枝へそろえる。この表示上の枝の選択は時間再帰へ影響しない。

`axis_errors`は上からロール誤差、ピッチ誤差、ヨー誤差、三軸の合成誤差の4段であり、各段に三条件を重ねる。各軸の誤差は、推定角と参照角の差を±180度の範囲へ折り返した絶対値とする。三軸の合成誤差は参照と推定の相対回転角であり、RPYの差の二乗和の平方根ではない。ピッチが±90度に近いとロール・ヨーの差が大きくなるため、下段と併せて読む。磁場方向の残差と磁場ベクトルのノルムは図に表示しない。

各軸の誤差は`rpy_error_deg`、三軸の合成誤差は`error_deg`として保存する。各条件の`statistics`は合成誤差の集計と`rpy_errors`内の各軸の集計を持つ。`--render-only`では、`script_sha256`は元の伝播を計算した版を保持し、`evaluation_script_sha256`に今回の評価・描画を行なった版を記録する。

各軸の片対数表示も別の図として出力する。`roll_error_semilog`、`pitch_error_semilog`、`yaw_error_semilog`のPDF/SVG/PNGを作り、各図に同じ三条件を重ねる。横軸は経過時間、縦軸は10を底とする対数で、三軸の縦軸範囲をそろえる。正の誤差値をそのまま描画し、0の標本は対数軸に表示しない。微小な正数への置き換えは行なわない。この記録では各軸とも「角速度」の初期時刻1標本が該当する。

保存済みの結果から静的な図だけを更新する場合は`--render-only --skip-video`を指定する。既存の動画を再生成しない場合は、動画を生成した版のSHA-256を`video_script_sha256`に保持する。

動画では、既存の`bingham.visualize.SO3s.draw_so3s`でBingham標本の軸端点とモードを描く。黒破線の軸がモーションキャプチャであり、右端には参照方位だけを表示する。下段の三軸の合成誤差とカーソルを同じ時刻にそろえる。

2025年3月10日の記録では、初期設定後の85.446秒、17,088標本に対する誤差の二乗平均平方根は次のとおりである。すべて度で示す。

| 条件 | ロール | ピッチ | ヨー | 三軸の合成誤差 |
| --- | ---: | ---: | ---: | ---: |
| 角速度 | 10.06 | 6.25 | 9.48 | 7.35 |
| 地磁気の融合あり（後処理のみ） | 7.69 | 4.95 | 7.53 | 6.15 |
| 地磁気の融合あり（次時刻の初期値にも利用） | 16.02 | 5.00 | 11.12 | 13.61 |

「地磁気の融合あり（後処理のみ）」では全項目が「角速度」より小さい。「地磁気の融合あり（次時刻の初期値にも利用）」ではピッチが「角速度」より小さい一方、ロール・ヨーと三軸の合成誤差が大きい。約67.6秒では参照ピッチが−90度に近づき、「角速度」のヨーの差が179.41度となる時刻でも三軸の合成誤差は9.55度である。各軸の誤差と方位全体の誤差は異なる指標である。
