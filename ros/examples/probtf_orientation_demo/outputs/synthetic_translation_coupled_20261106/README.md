# 並進加速度を含む独立IMU姿勢推定の比較

較正済みの人工IMU列から、姿勢とbody並進加速度を共同推定した。三つのシナリオごとに全方式が同じ測定列・初期姿勢・実取得時刻を使う。ドローンの機体同定、従来の実測結果、等方ノイズの人工動画とは別の実験である。

各30秒、gyroと加速度計は50Hz、地磁気は3tickごとの約16.7Hz。全1501出力を主統計に含め、成功区間や誤差の小さい区間で条件付けていない。生成側と推定側で異なる、全3×3の非等方センサ共分散を使う。各時刻の姿勢・並進加速度の真値は評価専用で、推定器へは初期姿勢と既知の重力・磁場だけを許す。

## ピッチRMSE

| 方式 | 並進なし | 周期的な並進 | 持続加速度 |
|---|---:|---:|---:|
| 提案法9軸 | 0.0774° | 0.0756° | 0.0628° |
| 提案法6軸 | 0.0905° | 0.1685° | 0.3111° |
| 重力のみの観測モデル9軸 | 0.0130° | 1.3983° | 2.8150° |
| Madgwick9軸 β=0.1 | 0.1365° | 2.7964° | 3.8776° |
| Madgwick6軸 β=0.1 | 0.1396° | 2.7971° | 3.8874° |
| Madgwick9軸 雑音RMSゲイン | 0.0440° | 0.1725° | 0.1963° |
| Madgwick6軸 雑音RMSゲイン | 0.0476° | 0.1730° | 0.1931° |
| gyro積分 | 0.0285° | 0.0285° | 0.0285° |

雑音RMSゲインは β=0.000782624。推定側ジャイロ共分散だけから β=0.5√trace(Σω) と決めた値で、真値に合わせた最適化ではない。β=0.1の結果も残す。

確率分布を持つ3方式の主評価は、ピッチ二乗誤差に対応する事後ピッチ平均。Madgwickとgyro積分は点姿勢のピッチを使う。全方式へ同じ初期姿勢の代表を与えるが、提案法は3度の不確かさを持つ初期分布であり、Madgwickには分布はない。

## この比較から分かること

9軸では、周期的並進で提案法0.0756°／Madgwickの雑音RMSゲイン0.1725°、持続加速度で0.0628°／0.1963°となった。並進加速度を状態として扱う構成で、これらの人工条件ではMadgwickと比較できる小さいピッチ誤差を得た。一方、並進なしでは提案法0.0774°／Madgwick0.0440°で、常に提案法が小さいわけではない。

6軸では周期的並進が0.1685°／0.1730°と近い。持続加速度では0.3111°／0.1931°で提案法の方が大きく、地磁気なしで持続加速度と重力方向を分ける課題は残る。β=0.1だけを比較対象にして一律の優越を主張しない。

有限3反復の射影は、連続分布の厳密な最小KL解ではない。最大モーメント残差は提案9軸で約8.21×10⁻⁷、6軸で約1.35×10⁻¹³、重力対照で約2.84×10⁻⁵だった。特に重力対照の一時的な分散増大には有限射影の影響があり、その分散をセンサ由来の不確かさそのものと解釈しない。積分の収束確認と、射影最適化・再帰全体の収束確認は区別する。

## 解釈の制限

加速度計だけでは、重力方向の変化と並進加速度を一意に分けられない。本方式は並進加速度の時定数0.7秒・定常標準偏差1.5m/s²・初期標準偏差0.3m/s²という運動事前を使う。この事前の正しさを本実験で保証したわけではない。Madgwickの標準実装にはこの状態・事前はなく、磁気dipも観測から求めるため、情報の使い方に構造的な差がある。

初期姿勢が正確で、較正済み・零ジャイロバイアス・小さい白色ノイズという条件なので、gyro積分自体が高精度になりうる。未知バイアス、初期誤差、別の並進過程、実測データに対する優越をこの1つの乱数実現値から主張しない。雑音の設定値は連続時間のパワースペクトル密度ではなく観測1回当たりの共分散であり、元の60秒・200Hz設定と同じ雑音過程を間引いた実験でもない。

観測因子のGaussian周辺化・条件付き更新・係数加算は指定モデル内で解析的。時間予測は既存coreのquaternionモーメントを使うが、増分Binghamという過程モデル、19係数族への有限forward-KL射影、適応した多中心の決定論的積分は明示的な近似である。粒子・モンテカルロ推定は使わない。実装はオフライン参照であり、センサ周期のリアルタイム性能を示すものではない。
