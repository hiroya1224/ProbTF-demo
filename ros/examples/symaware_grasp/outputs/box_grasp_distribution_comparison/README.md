# 正方形底面の箱の四側面に対応する把持分布

寸法100×100×180 mmの箱に対し、上向きのz軸を保ち、物体z軸周り0・90・180・270度の四回転を一つの混合分布として配信した。各成分のx軸は一つの側面の外向き法線で、四つの側面を一つずつ覆う。原点は箱中心に共通である。混合条件の重みは各0.25、集中度は全成分5000。単一条件は同じ基準モードの一成分を用いる。

箱の位置(0.78, −0.12, 0.46) m、基準ヨー67.5度、逆運動学、初期関節角、費用の重み、制御器と接近・閉鎖処理は両条件で同じである。方位費用は正規化済み混合密度の負の対数をlog-sum-expで評価する。ROS masterをport11982へ分離し、二条件を順に実行した。

| 量 | 四成分混合 | 単一成分 |
|---|---:|---:|
| 位置誤差 mm | 0.000358034 | 0.000896798 |
| 最寄りモード方位誤差 deg | 0.053158483 | 0.052339463 |
| 手首曲げ角 deg | 28.101799801 | 92.371814125 |
| 指方向の箱の投影幅 mm | 100.108740866 | 100.103501398 |
| 重み付け前の移動量費用 | 1.530358949 | 3.509213032 |
| 全観測の最小箱隙間下限 mm | 2.954266061 | 2.647277976 |

両条件で位置・方位・開口量の基準を満たした。混合条件は基準から270度（−90度）回したモードの近傍を選び、単一条件は基準モード近傍へ到達した。この一例での手首角と移動量の差を示すもので、一般的な優位性や接触・摩擦・保持力・持上げを評価したものではない。

動画は一つのX11画面を分岐して保存し、各条件の斜め・真上・横並びは同じフレーム数と20 fpsを持つ。赤x=180 mm、緑y=120 mm、青z=180 mmは表示用の軸長であり、xとyの点群が重なって四方向を見失わないために分けた。物理寸法や不確かさの大小を表す数値ではない。図内の説明字幕は追加していない。

bag、CSV、summary、manifest、設定、URDFとRViz設定、最終画像と動画を保存した。再解析と新しい比較の実行は次のとおり。

```sh
rosrun symaware_grasp run_box_grasp_demo.py analyze /absolute/path/to/mixture --output /tmp/square-box-analysis
rosrun symaware_grasp run_box_grasp_demo.py compare --output /tmp/new-square-box-comparison --port 11982
```

この保存先には今回の正しい四側面構成だけを置く。誤った旧構成の映像・記録は削除し、正しい試行から再生成した。実行logとROS内部cacheは共有資料から除外する。
